# Reserve/ —— 预留特性代码区（不参与编译）

这个目录里的代码**没有加入 Keil 工程，不参与主固件编译**。
它们是"写好了、单独编译验证过、但需要在真电机上慢慢调"的高级特性，
留给你按需要一个一个接进工程。

## 完整接入/调试教程

**看 [Docs/09_预留特性接入手册.md](../../../../Docs/09_预留特性接入手册.md)**
——每个特性怎么加进工程、怎么调、成功判据、失败回退，都在里面。

## 文件清单

| 文件 | 特性 | 一句话 |
| ---- | ---- | ---- |
| `foc_sensorless.c/.h` | 无感 FOC | 中高速免编码器（开环启动→观测器闭环） |
| `foc_hfi.c/.h` | HFI 低速无感 | 高频注入，静止也能定位（需凸极电机） |
| `foc_anticog.c/.h` | 抗齿槽 | 标定+前馈，低速丝滑 |
| `foc_fieldweaken.c/.h` | 弱磁扩速 | 注入负 Id 冲破反电动势限速 |
| `foc_can.c/.h` | CAN 总线 | 远程控制 + 状态广播（需收发器芯片） |

## 三条纪律

1. **用 Keil GUI 加文件**（右键分组 → Add Existing Files），
   不要手改 `.uvprojx`（改坏会导致工程打不开）；
2. **一次只接一个**，台架验证通过再接下一个；
3. 每个都依赖某些前置条件（电流环/速度环已调好、特定硬件），
   前置不满足别硬接——见 09 手册各章"前置条件"。

> 这些代码引用主工程的 `Core/`、`App/` 头文件（相对路径 `../`），
> 已用 armcc 单独编译验证通过（0 error）。接进工程后若报
> "未定义的枚举/全局"，是因为部分接入点需要你在主工程里加一个
> 枚举值或全局对象——09 手册对应章节有说明。

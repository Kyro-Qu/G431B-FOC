## 术语速查（读文档时回来查）

| 术语 | 意思 |
| ---- | ---- |
| FOC / 磁场定向控制 | 把电流精确控制在最能产生转矩的方向上的算法 |
| Clarke / Park 变换 | 三相 → 两相静止 → 两相旋转坐标系的数学工具 |
| d 轴 / q 轴 | 旋转坐标系两个轴：d 指向转子磁极（不产转矩），q 垂直（产转矩） |
| Id / Iq | 电流在 d/q 轴的分量；通常控制 Id=0、Iq=想要的转矩 |
| SVPWM | 空间矢量调制：把目标电压翻译成三相占空比（本工程用中点注入法） |
| 电角度 θe | 转子磁场的角度 = 机械角 × 极对数 + 偏移，Park 变换用它 |
| 极对数 pp | 转子磁铁对数；电机转一圈，电角度转 pp 圈 |
| 级联环 | 位置环套速度环套电流环，外环输出是内环给定 |
| CPR | 编码器每转计数（线数×4） |
| Z 脉冲 / index | 编码器每圈一次的基准脉冲，校准用 |
| 校准 / 偏移 | 建立"编码器读数 ↔ 电角度"映射的过程及其结果 |
| ARR / CCR | 定时器周期寄存器 / 比较寄存器（决定 PWM 频率/占空比） |
| MOE | 高级定时器主输出使能——功率级的总闸 |
| 注入组 | ADC 的高优先级转换通道，由 PWM 定时器硬件触发 |
| 自举（bootstrap） | 给高边 MOS 驱动供电的电容，上电要先充电 |
| 死区 | 上下管切换间隙，防直通（本板约 740ns） |
| IWDG | 独立看门狗：程序挂死时硬件复位 |
| foc-studio / FOC-STP | 网页上位机及其自解释掩码遥测协议（[11 篇](11_FOC-STP遥测协议.md)） |
| Rs / Ls | 电机相电阻/相电感，电流环自整定的依据 |
| 堵转 | 电机被卡住转不动还在灌电流的状态 |

## 基准性能指标速查（DJI 2312S + 14.4V + 16kHz PWM 实测）

- **双模控制闭环**：
  - **全速域纯有感**：ABZ 增量编码器（2048 CPR），全速域 0 ~ 8000+ RPM 闭环稳定；
  - **纯无感主控模式（Sensorless Primary）**：I/F 平滑拖动（0.55A, 400ms 吸附）自适应无扰接管至 VESC 约束磁链闭环（500 ~ 2000 RPM 稳态巡航，800 RPM 速度波动 < 10 RPM，误差仅 1.2~5.5 RPM）；
  - **无感自动故障接管（Fallback）**：中高速编码器故障 150ms 动基准衰减平滑切入无感，10/10 次 100% 成功。
- **极对数**：实测 7 对极（12N14P 外转子，绝非 6！）
- **低速控制**：20 ~ 100 RPM 稳定可控；
- **主力巡航**：2400 RPM 稳态误差 $\pm 9 \sim 11\text{ RPM}$，空载电流仅 $0.14\text{A}$；
- **弱磁与超频极限**：8000+ RPM 稳态达成（超频可冲至 8997.9 RPM，母线利用率 82%~86%）；
- **位置控制**：梯形轨迹加减速平滑，多圈阶跃到位静差 $< 1.5^\circ$ 机械角，运行态旁路 Z 脉冲保障零累积误差；
- **断电恢复**：Flash 参数与零偏固化，上电后快速索引寻 Z 仅需 1.5 秒即可直接就绪进入闭环；
- **安全保护闭环**：七层安全网覆盖，纯无感失锁 10ms 识别并受控关断 PWM 转入 SAFE_STOP（fault=9），杜绝飞车与炸机。

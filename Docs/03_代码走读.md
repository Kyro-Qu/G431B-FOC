# 03 · 代码走读

> 按"从底层到上层"的顺序讲每个文件。建议开着代码对照读。
> 标 ★ 的函数是理解本工程的关键路径。

---

## 1. Core/foc_utils.h —— 数学工具

全是内联小函数，快环里零调用开销：

| 函数 | 作用 | 用在哪 |
| ---- | ---- | ---- |
| `foc_clampf(x, lo, hi)` | 限幅 | 到处都是 |
| `foc_wrap_0_2pi(a)` | 角度归一化到 [0, 2π) | 电角度 |
| `foc_wrap_pm_pi(a)` | 角度差归一化到 [-π, π) | 多圈位置解算、位置误差 |
| `foc_max3/min3` | 三者取大/小 | SVPWM 中点注入 |

`foc_wrap_pm_pi` 值得多看一眼：编码器角度是 0~2π 循环的，直接相减会在
2π→0 跳变处得到 -6.28 的假增量；先 wrap 到 ±π 就能得到真实的小增量。
`foc_motor_fast_loop` 里的多圈位置累计就靠它：

```c
m->position_rad += foc_wrap_pm_pi(th - m->theta_mech);
```

## 2. Core/foc_types.h —— 类型与接口表

三个坐标系向量（`abc_t`、`ab_t`、`dq_t`）、四个枚举（状态/模式/角度源/故障码）、
三张硬件接口表、参数与配置结构体。**这是唯一被所有层包含的头文件**，
所以它自己不包含任何硬件头。设计意图见文件头注释和 02 篇。

## 3. Core/foc_pid.c —— PID 与低通（学 SimpleFOC）

★ `foc_pid_update(pid, error, dt)`，四步：

```c
proportional = kp * error;
integral    += ki * dt/2 * (error + prev_error);   // ① Tustin 积分
integral     = clamp(integral, ±out_limit);        // ② 抗积分饱和
output       = clamp(P + I + D, ±out_limit);       // ③ 输出限幅
output       = ramp_limit(output, out_ramp * dt);  // ④ 输出斜坡
```

- ① 用梯形面积代替矩形面积做数值积分，相位误差更小；
- ② 是**抗饱和（anti-windup）**：没有它，电机堵转几秒后积分项会涨到天上，
  解除堵转的瞬间电机会疯冲——这是新手最常踩的坑；
- ④ 限制输出变化率（如 V/s），把阶跃命令变成斜坡，保护机械和电源。

`foc_lpf_update`：一阶低通 `y += dt/(Tf+dt)·(x-y)`，Tf 是时间常数。
Tf=0 直通。速度反馈、dq 电流遥测都用它。

## 4. Core/foc_transform.h —— Clarke/Park

四个变换的公式实现（见 01 篇原理）。两个工程细节：

1. sin/cos 用 CMSIS-DSP 的 `arm_sin_f32`（查表+插值，M4 上比 sinf 快约 5 倍）。
   非 ARM 平台自动退回标准库——所以这个头文件可以在 PC 上编译测试。
2. `foc_park`/`foc_inv_park` 接收**已算好的 sin/cos**，而不是角度。
   因为快环里 Park 和反 Park 用同一个角度，sin/cos 只算一次（省一半三角函数）。

## 5. Core/foc_svm.c —— SVPWM

★ `foc_svm_calc(v_ab, u_dc, out)`：

```c
foc_inv_clarke(v_ab, &v);                 // αβ → 三相目标电压
span = max - min;
if (span > u_dc) 等比缩放;                 // 过调制保护
v_common = -(max + min) / 2;              // 中点（零序）注入
duty_x = 0.5 + (v_x + v_common) / u_dc;   // 归一化到占空比
```

纯函数：不碰硬件、不读全局，同样输入永远同样输出——可以直接在 PC 上
用几组已知矢量验证（如 α=1,β=0 时 duty_a 应最大且 sector=1 附近）。

扇区号用符号判断法算出，仅供电流采样窗口规划和调试观察。

## 6. Core/foc_motor.c —— 电机对象（工程心脏）

### 6.1 ★ foc_motor_init：电流环自动整定

```c
kp_i = Ls * ω_bw;    ki_i = Rs * ω_bw;    // ODrive 带宽整定法
```

还做了所有 PID 的输出限幅配置：
- 电流环输出限幅 = Udc/√3（SVPWM 线性区上限）；
- 速度环输出限幅 = 最大电流；
- 位置环输出限幅 = 位置模式速度上限。

**每一级的输出限幅就是下一级的安全边界**——级联控制的免费保险。

### 6.2 ★ foc_motor_fast_loop：16 kHz 快环

对照 02 篇的数据流图读代码，几个容易疑惑的点：

- **为什么传感器更新放在最前、且任何状态都执行？**
  这样 IDLE 时也能在 VOFA 里看到手转电机的角度/速度——排查编码器问题不用上电。
- **为什么先读电流做保护、再算控制？**
  安全永远第一。过流后本拍直接 return，绝不再写 PWM。
- **`pwm_hold` 是干嘛的？**
  校准的自举充电阶段要求三相下管全通（CCR=0），此时快环不能用正常的
  中点占空比覆盖它。pwm_hold=1 时快环跑到保护为止就返回。
- **CALIB 状态为什么强制走开环角度？**
  校准就是在"用开环电压摆转子"，此时编码器偏移还没算出来，闭环角度无意义。

### 6.3 foc_motor_slow_loop：1 kHz 慢环

速度模式：目标先过**斜坡限幅**（加速度限制），再进速度 PI。
位置模式：位置 P 输出速度给定（限幅），级联进速度 PI。
输出 iq_ref 统一钳位到 ±max_current。

### 6.4 过流保护 foc_motor_check_current

双阈值策略（继承旧工程验证过的逻辑）：
- **软限制**：连续 8 拍（0.5ms）超过 → 跳闸。容忍单拍毛刺；
- **硬限制**：任何单拍超过 → 立即跳闸。
跳闸动作：锁存三相电流快照 → `foc_motor_fault()`（关 MOE + 锁存故障码）。

### 6.5 电压圆限幅 foc_voltage_circle_limit

电流环输出的 (Vd,Vq) 合成幅值不能超过 Udc/√3。超了怎么裁？
**d 轴优先**：先保 Vd（维持磁场定向），裁 Vq（牺牲一点转矩）。
这是 MCSDK/VESC 的通行做法，反过来裁会在高速时失去定向、直接失控。

## 7. Driver/encoder/abz_encoder.c —— 编码器

核心是 ★`abz_encoder_update()`（快环里调用）：

```c
delta = CNT_now - CNT_last;              // 半量程法处理 16 位回绕
delta 超过 1/4 圈 → 视为干扰丢弃;
position = (position + delta) mod CPR;   // 单圈位置
angle = position × (2π/CPR);
速度 = 5点去极值均值(delta) × 系数 → 一阶IIR;   // 两级滤波
```

**半量程法**为什么绝对可靠：16 kHz 采样下电机要一拍转过半圈（32768 计数）
需要 490 万 RPM——物理不可能，所以 |delta|>半量程必然是回绕。

**Z 脉冲处理**是并发设计的范例：Z 中断（EXTI）只锁存 CNT 并置标志
（`abz_encoder_on_index`），真正的清零在下一拍 `update()` 里做——
保证 last_cnt/position/CNT 三者永远在同一上下文中被修改，没有竞态。

## 8. Driver/current/current_shunt.c —— 电流采样（硬件验证过的核心资产）

这是全工程最"硬"的文件，时序继承 ST MCSDK R3_2 并在本板验证。只需理解三件事：

1. **谁触发采样**：TIM1 CH4 的比较事件（OC4REF→TRGO→ADC 注入组）。
   CH4 不接引脚，纯粹当"采样闹钟"用，每拍由软件重新规划闹钟时刻。
2. **采哪两相**（`current_shunt_prepare_pwm`）：占空比最大的相，低边导通窗口最短，
   放弃它，采另外两相，用 Iu+Iv+Iw=0 重构。窗口太窄时还会挪采样点、
   甚至翻转到下降沿触发——这些 if 分支就是 MCSDK 的窗口规划策略。
3. **为什么用注入组+每拍重写 JSQR**：G4 的 ADC 注入上下文是队列式的，
   驱动在 TIM 更新中断里提交"下一拍采什么"，在 ADC 中断里消费结果，
   两边用 `contexts_armed` 握手，任何不一致立即 `current_shunt_fail()` 关功率级。

诊断结构 `g_current_shunt_diag` 在 Keil Watch 里加上，采样链路的一切
（原始码值、零偏、状态、故障码、寄存器快照）一目了然。

## 9. HAL/foc_board_g431.c —— 板级绑定

把硬件包成三张接口表。PWM 部分三个要点：

- **上电顺序**（`foc_board_init`）：MOE 关 → 比较值预置中点 → 计数器定位到
  ARR-1 向上 → 启动 CH4 → 装配六路 CCER。全程功率级都是关的。
- **自举充电**（`m0_pwm_bootstrap`）：高边 MOS 的驱动电压靠自举电容，
  上电后电容是空的，直接开高边会"开不动"。先让三相低边全通 10ms 充电。
- **写比较值前临时关预装载**（`set_neutral_now`）：否则新值要等下个周期
  才生效，重新使能 MOE 的瞬间会输出上一次运行残留的旧占空比——真实烧过管的教训。

轴 1 的虚拟接口表也在这个文件底部，替换成真硬件的方法见 05 篇。

## 10. App 层四个模块

### foc_app.c —— 组装与调度
- `foc_app_init()`：初始化顺序是**安全链**：电机对象 → 编码器 → 电流采样链路
  （失败直接 FAULT，PWM 永远不会开）→ PWM 定时器（MOE 保持关）→ 零偏校准
  （还是不开 MOE）→ 通信。任何一步失败，后面都不会给电机上电。
- `foc_app_on_key()`：IDLE→(闭环模式先校准)→RUN→IDLE 的按键循环。

### foc_calib.c —— 上电校准状态机
七个状态的毫秒级流程（见文件头注释流程图）。安全细节：
- 校准期间电流阈值压到 1.5A/3.0A；
- 电压都从 0 **缓升**（200ms 斜坡），静止低阻电机上直接加压等于短路测试；
- 任何异常（超时/过流/采样失效）→ 恢复阈值 → FAULT。

### foc_cmd.c —— 串口命令行
DMA+空闲中断收字节 → 回调只搬运 → 主循环解析执行。命令表见 04 篇。
**回调里绝不解析绝不打印**——中断上下文只做 O(n) 的字节拷贝。

### foc_telemetry.c —— VOFA 遥测
JustFloat 协议（16 float + 帧尾），1 kHz，DMA 发送。
上一帧没发完就丢弃本帧（绝不在中断里等）。通道表见文件头注释。

## 11. Core/Src/main.c 里保留的"黑匣子"

`system_power_checkpoint()` / `system_fault_diag_boot_init()`：
利用 TAMP 备份寄存器（复位不丢）记录每次功率级操作前的状态快照。
如果调试中发生"电机一上电 MCU 就复位/掉调试器"这类恶性问题，
重新上电后在 Keil Watch 看 `g_system_fault_diag` 就能知道
复位前最后一个检查点、当时的 TIM1 寄存器、复位原因——
这是排查功率级引起的电源跌落/EMI 复位的黑匣子，调试期强烈建议保留。

## 12. Core/foc_traj.c —— 梯形轨迹规划（ODrive trap_traj 移植）

位置模式的"翻译官"：把跳变的目标位置翻译成限速、限加速度的平滑曲线。
`foc_traj_plan()` 一次算好三段时长（加速/巡航/减速），短行程自动退化
三角形，支持带初速度重规划（运动中改目标不抽搐——先按减速距离判断
净方向）；`foc_traj_eval()` 每个慢环拍输出（位置参考, 速度前馈）。
速度前馈直接叠加到速度给定上，位置环 P 只负责修残差——这是它比
"纯位置 P 硬拉"平滑得多的原因。慢环集成点在 `foc_motor_slow_loop()`
的 POSITION 分支，`FOC_M0_TRAJ_ENABLE=0` 可退回旧行为。

## 13. App/foc_ident.c —— Rs/Ls 参数自动测量（ODrive/VESC 方案）

串口 `id` 触发，两步走：
- **Rs**：θe 锁 0，积分控制器缓升 d 轴电压直到电流达 1A，取 400ms
  平均：Rs = V̄/Ī（转子被吸住，无反电动势干扰）；
- **Ls**：d 轴注入 ±0.15V 方波（快环每拍翻转极性），电流走三角波，
  按极性累计"伏秒"与"电流增量"：Ls = Σ(V−Rs·i)dt / Σdi。
  已用刚测出的 Rs 修正电阻压降，一拍传输延迟也做了记账对齐。

注入通道是 `foc_motor_t.test_hook`——CALIB 状态下快环每拍调用的
测试钩子，这是给所有"注入式测量"（以后 HFI 也一样）预留的标准入口。
全程使用校准级低电流阈值，任何异常立即断 PWM。

## 14. 预留模块（已编译，未绑定）

按"好代码先留在工程里"的原则，两个模块随工程编译（链接器会剔除未引用代码，
不占固件体积），需要时按头文件注释接入：

- **Core/foc_observer.c**：VESC 式无感磁链观测器 + PLL。
  核心是 Ortega 观测器——用"转子磁链幅值恒定"这一物理约束修正积分漂移，
  atan2 取磁链方向即电角度；PLL 再滤出平滑转速。做无感 FOC 时把它的输出
  接到 angle_source 即可（起动仍用开环拖动）。
- **Driver/hall/hall_sensor.c**：霍尔传感器驱动（本板 H1~H3 与 ABZ 共用引脚）。
  120° 霍尔编码 → 60° 扇区 → 边沿测速 + 转速积分插值得到连续角度。

# 07 · 移植指南 —— 把这套 FOC 搬到你自己的板子上

> 本工程从第一行代码就是按"可移植"设计的：算法层不认识任何寄存器，
> 硬件被隔离在两个目录里。本篇告诉你：移植时**哪些文件动、哪些不动、
> 按什么顺序动、每一步怎么验证**。

---

## 0. 先想明白：分层决定移植面

```
                                          移植时……
┌────────────────────────────────┐
│ Core/   纯算法（FOC/PID/SVM/轨迹）│  ← 一行都不改
├────────────────────────────────┤
│ App/    业务（校准/命令行/遥测）   │  ← 一行都不改
├────────────────────────────────┤
│ Driver/ 设备驱动（编码器/电流采样）│  ← 换传感器/采样拓扑时改
├────────────────────────────────┤
│ HAL/    板级绑定（接口表/config） │  ← 必改（这就是为你准备的）
├────────────────────────────────┤
│ CubeMX  外设初始化（main.c 等）   │  ← 必改（图形化配置）
└────────────────────────────────┘
```

Core/App 能不动的原因：它们只通过 `foc_types.h` 里的**三张函数指针
接口表**（driver / current / sensor）访问硬件。移植的本质就一句话：
**用 CubeMX 配好外设，然后把三张接口表填上你的实现。**

## 1. 三种移植场景的难度

| 场景 | 改动范围 | 工作量 |
| ---- | ---- | ---- |
| A. 同为 STM32G4 的另一块板（引脚/采样电阻不同） | CubeMX + foc_config.h | 半天 |
| B. 换 STM32 型号（F4/G0/H7…） | A + foc_board/foc_store 适配 | 1~2 天 |
| C. 换位置传感器（SPI 磁编码器/霍尔） | 新增一个 Driver + 改接口表绑定 | 1 天 |
| D. 换电流采样拓扑（单电阻/inline） | 重写 current_shunt 的窗口规划 | 最难，数天 |

## 2. 场景 A：同类板卡移植（照抄清单）

### 2.1 CubeMX 外设配置要求（每一项都有原因）

**高级定时器（TIM1 或 TIM8）—— 三相 PWM：**

| 配置 | 值 | 为什么 |
| ---- | ---- | ---- |
| 计数模式 | Center Aligned mode 1 | 中心对齐让电流采样点落在零矢量中点，纹波最小 |
| ARR | 时钟/(2×PWM频率)，如 170M/(2×16k)=5312 | 决定 PWM 频率 |
| CH1/2/3 | PWM Generation CHx CHxN（互补输出） | 三相半桥上下管 |
| 死区 | 按驱动芯片要求（本板 63 → 约 740ns） | 防上下管直通 |
| CH4 | PWM Mode 2，无输出 | **专职产生 ADC 触发点**（关键！） |
| TRGO | OC4REF | CH4 比较事件 → 触发 ADC 注入组 |
| Repetition Counter | 1 | 每整周期一次 update 中断 |
| OSSR/OSSI | Enable | MOE 关闭时输出确定的安全电平 |

**ADC —— 电流采样（注入组）：**

| 配置 | 值 | 为什么 |
| ---- | ---- | ---- |
| 注入组转换 | 使能，外部触发 = TIM1 TRGO，上升沿 | 与 PWM 硬同步，每周期定点采样 |
| 注入通道 | 三相采样对应通道（可分布在 ADC1/ADC2 上并行） | 两相同时采，缩短窗口 |
| 采样时间 | 尽量短（本板 6.5 周期） | 低边采样窗口有限 |
| 常规组 | 不用 | 注入组独占，时序确定 |

**编码器定时器（TIM2/3/4/5 任一 32/16 位均可）：**
Encoder Mode TI1+TI2、ARR=65535、输入滤波 ~15；Z 相接一个 EXTI
（上升沿）。

**串口：** 任意 USART + TX/RX DMA；波特率按你的 USB 转串口能力
（`foc_config.h` 里没有波特率——它在 CubeMX 里）。

**NVIC 优先级（最容易踩的坑，照抄本板验证过的关系）：**

| 中断 | 抢占优先级 | 理由 |
| ---- | ---- | ---- |
| TIM1_UP（PWM update） | 0（最高） | 里面提交下一拍的 ADC 注入触发配置（JSQR），必须先于一切 |
| ADC1_2（JEOS，快环） | 2 | 电流环本体；必须低于 TIM1_UP |
| EXTI（编码器 Z） | 0 | 只锁存计数，几条指令，不能被延迟 |
| USART/DMA/按键 | ≥5 | 通信不许打扰控制 |

### 2.2 `foc_config.h` 修改清单

```
FOC_PWM_ARR / FOC_PWM_FREQ_HZ    ← 与 CubeMX 的 TIM 配置一致
FOC_UDC_V                        ← 你的母线电压
FOC_M0_POLE_PAIRS / RS / LS      ← 你的电机（或烧录后用 id 测）
FOC_M0_MAX_CURRENT_A / HARD      ← 按功率级和电机取小者
FOC_M0_ENCODER_CPR               ← 编码器线数 × 4
FOC_CALIB_*                      ← 校准电压先取小（0.2~0.3V 起步）
```

### 2.3 电流采样换算（`current_shunt.h`）

本板：20mΩ 采样电阻 × OPAMP PGA 16 倍（实测等效 1.371×16≈21.9 V/V 链路，
详见头文件注释）。你的板子按公式改：

```
电流 (A) = (ADC读数 - 零偏) × Vref / 4096 / (Rshunt × 总增益)
```

只改 `CURRENT_SHUNT_*` 那几个宏，换算逻辑不用动。

### 2.4 引脚与接口表

引脚变化对代码**零影响**（CubeMX 管），除非换了定时器实例——
那就把 `foc_board_g431.c` 里的 `htim1` 换成你的句柄。

## 3. 场景 B：换 STM32 型号

在场景 A 之上，额外检查四件事：

1. **OPAMP**：F4/F1 没有内置运放 → 板上必须有外部运放，删掉
   `MX_OPAMPx_Init` 相关；G4/F3/H7 系有内置。
2. **ADC 注入组触发源**：不同系列的 TRGO 映射编号不同，在 CubeMX
   里选对"TIM1 TRGO → 注入组"即可，HAL 宏名自动正确。
3. **`foc_store.c` 的 Flash 几何**：页大小/页数因型号而异
   （F4 是不等长扇区！），改 `STORE_ADDR/STORE_PAGE` 和擦除调用；
   F4 用 `FLASH_Erase_Sector`。同时把 Keil 目标里的 IROM 尺寸
   减去存储区，让链接器帮你护住它。
4. **时钟频率**：`foc_board_g431.c` 里 CPU 统计的 `170000000.0f`、
   `foc_cmd.c` 状态打印里的同值，改成你的主频（或提成宏）。

其余 Core/App/Driver 代码与芯片无关。

## 4. 场景 C：换位置传感器

### 4.1 传感器接口契约（`foc_types.h` → `foc_sensor_if_t`）

实现下面这张表就能接入任何传感器，Core/App 一行不改：

| 函数 | 调用上下文 | 契约 |
| ---- | ---- | ---- |
| `update()` | 16kHz 快环（中断） | 刷新内部状态，必须几 µs 内返回 |
| `angle_rad()` | 快环 | 机械角 [0, 2π)，弧度 |
| `velocity_rpm()` | 快环 | 机械转速 RPM，建议内部滤波 |
| `force_zero()` | 校准状态机（主循环） | 把当前位置设为零点 |
| `set_zero_on_index(en)` | 校准状态机 | Z 脉冲到来是否自动清零 |
| `consume_index(&cnt)` | 校准状态机 | 取出一次 Z 事件（一次性消费） |
| `rad_per_cnt` | 常量 | 每计数的机械弧度 |

后三项是"带 Z 脉冲的增量编码器"专用；**绝对式传感器置 NULL**，
并跳过 Z 搜索（见 4.2）。

### 4.2 例：SPI 磁编码器（AS5047P / MT6701）

绝对编码器上电即知绝对角，**根本不需要 Z 搜索校准**——只需要一次
D 轴对齐测 offset（可以做完存 Flash，永久有效）。骨架：

```c
/* Driver/encoder/as5047.c（自己新建） */
static uint16_t raw;                  /* 14 位绝对角 */
void as5047_update(void) {            /* 快环调用：发起/收取 SPI */
    raw = spi_read_angle();           /* 建议 DMA 或来不及就隔拍读 */
}
float as5047_angle_rad(void) { return raw * (_2PI / 16384.0f); }
float as5047_velocity_rpm(void) { /* 差分 + 低通，参考 abz 的做法 */ }

const foc_sensor_if_t g_board_m0_sensor = {
    .update = as5047_update,
    .angle_rad = as5047_angle_rad,
    .velocity_rpm = as5047_velocity_rpm,
    .force_zero = 0, .set_zero_on_index = 0, .consume_index = 0,
    .rad_per_cnt = _2PI / 16384.0f,
};
```

校准改造：绝对编码器的 offset = D 轴对齐时的 `dir·pp·θm` 取负
（让对齐点电角度为 0）。最简单的做法：沿用现有校准状态机到
ALIGN 结束，直接在那一步算 offset 并置 valid，跳过 SEARCH——
`foc_calib.c` 里加一个 `sensor->consume_index == NULL` 的分支即可。

### 4.3 霍尔传感器

`Driver/hall/hall_sensor.c` 已经写好（扇区 + 插值 + 超时保护），
按其头文件注释接 EXTI 和接口表即可。

## 5. 场景 D：换电流采样拓扑（如实告知：这是最难的）

`current_shunt.c` 是**三电阻低边采样**的实现，其核心价值在
`current_shunt_prepare_pwm()`：根据三相占空比和扇区，每周期动态决定
"采哪两相、什么时刻采、窗口不够时怎么办"。这套窗口规划逻辑与拓扑
强耦合：

- **三电阻低边**（本工程）：低边导通时采样，大占空比时窗口变窄，
  需要窗口规划 → 现成可用；
- **双电阻低边**：删掉第三相重构，逻辑同源，改动中等；
- **单电阻母线采样**：需要相移 PWM + 一周期两次采样重构三相电流，
  窗口规划完全不同 → 等于重写该文件（可参考 MCSDK 的 R1 实现）；
- **inline 电流传感器**（如 INA240）：任意时刻可采，窗口规划直接
  退化为"固定中点采样"，反而最简单——`prepare_pwm` 可以变成空函数。

接口不变（`foc_current_if_t` 只有 `is_ready`/`get` 两个函数），
所以无论怎么换，Core/App 依然一行不改。

## 6. 移植后的验证顺序（不许跳步）

在 [04 · 上手指南](04_上手指南.md) 的逐层验证之前，先做移植特有的
三项"零电压检查"（全程不使能功率级）：

1. **编码器**：手转轴，VOFA ch1 机械角应平滑爬升且每圈回零；
   反了就对调 A/B（或者接受它，校准会用 direction 处理）。
2. **零偏**：上电打印的三相零偏应在 2048±500；偏得远 = 运放
   偏置电路或增益配置有问题。
3. **采样触发**：`s` 查看 CPU 占用非零、`g_current_shunt_diag`
   无故障计数增长——说明 TIM 触发 ADC 的链路通了。

然后按 04 的第 1~5 层逐层来（开环 → 校准 → 力矩 → 速度 → 位置），
**第一次一定串限流电源**。

## 7. 移植踩坑速查

| 症状 | 大概率原因 |
| ---- | ---- |
| ADC 中断从来不进 | CH4 没配 PWM Mode 2 / TRGO 没选 OC4REF / 注入组触发边沿不对 |
| 电流全是 0 | OPAMP 没 start / ADC 通道对应错引脚 |
| 零偏正常但一使能就过流跳闸 | 相序与采样通道对应关系错（U 采到 V 的电流） |
| 开环正转编码器读数反走 | 正常现象，校准的 direction 会处理；也可对调 A/B |
| 校准成功但闭环飞车 | `FOC_CALIB_DIRECTION` 需要取反（见 04 §5.4 注意事项） |
| 高速时波形每圈跳一下 | Z 每圈清零没关（本工程校准成功后自动关，移植改动时别丢） |
| 板子随机复位 | 看门狗没喂（主循环被阻塞）——查 TAMP 黑匣子定位 |

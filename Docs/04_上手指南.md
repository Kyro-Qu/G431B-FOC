# 04 · 上手指南：各控制模式的使用方法与命令

本节按模式整理串口操作流程。除 V/F 模式外，`iq`、`vel`、`pos` 都是闭环模式，必须先完成编码器校准。模式切换只允许在 `IDLE` 状态执行；如果当前是 `RUN`，先发送 `disable`。

## 5.5.1 V/F 开环模式（`mode vf`）

V/F 模式直接设置开环电压和开环转速，适合首次上电、检查功率级、三相顺序和电机转向。此模式不能使用 `target`，必须分别使用 `vq` 和 `rpm`。

| 命令 | 作用 | 示例 |
| ---- | ---- | ---- |
| `mode vf` | 选择 V/F 模式，必须在 IDLE 执行 | `mode vf` |
| `vq [V]` | 查询或设置 V/F Boost 电压 | `vq 0.3` |
| `rpm [RPM]` | 查询或设置开环转速，负值反转 | `rpm 100` |
| `vf` | 查看 V/F 曲线和斜坡参数 | `vf` |
| `vf slope <V/RPM>` | 设置 V/F 曲线斜率 | `vf slope 0.0006` |
| `status` | 查看实际应用电压和转速 | `status` |

推荐操作顺序：

```text
disable
mode vf
vq 0.3
rpm 50
enable
status
```

确认方向和电流正常后，再逐步增加 `rpm`。停止时执行：

```text
rpm 0
vq 0
disable
```

V/F 模式下实际电压还会按照转速和 `vf slope` 计算，并经过斜坡限制，不要一开始设置过大的 `vq`。`vq` 和 `rpm` 当前只对 M0 的 V/F 模式有效。

## 5.5.2 力矩/电流闭环模式（`mode iq`）

`iq` 模式的 `target` 单位是安培，表示 q 轴电流目标。正负值对应相反的电磁转矩；空载时给定电流会使电机加速。

| 命令 | 作用 | 示例 |
| ---- | ---- | ---- |
| `mode iq` | 选择力矩模式，必须在 IDLE 执行 | `mode iq` |
| `target [A]` | 查询或设置 q 轴电流目标 | `target 0.2` |
| `current` | 查询电流环参数 | `current` |
| `current bw <rad/s>` | 设置电流环带宽，必须在 IDLE 执行 | `current bw 1000` |
| `limit [A]` | 查询或设置软件电流限制 | `limit 2.0` |
| `status` | 查看 `iq` 与 `iq_ref` 跟踪情况 | `status` |

```text
disable
mode iq
current bw 1000
target 0
enable
target 0.2
status
```

测试结束先将目标降为零，再发送 `disable`。`target` 不能超过当前 `limit`；电流振荡时降低 `current bw`。

## 5.5.3 速度闭环模式（`mode vel`）

`vel` 模式的 `target` 单位是 RPM。速度环根据编码器速度反馈产生 q 轴电流，因此必须先完成 `calib full` 或有效的快速校准。

| 命令 | 作用 | 示例 |
| ---- | ---- | ---- |
| `mode vel` | 选择速度模式，必须在 IDLE 执行 | `mode vel` |
| `target [RPM]` | 查询或设置速度目标，负值反转 | `target 500` |
| `vel` | 查看速度环参数 | `vel` |
| `vel kp <value>` | 设置速度比例增益 | `vel kp 0.001` |
| `vel ki <value>` | 设置速度积分增益 | `vel ki 0.0001` |
| `vel ramp <RPM/s>` | 设置速度斜坡 | `vel ramp 300` |
| `vel filter <Hz>` | 设置速度滤波频率 | `vel filter 30` |
| `vel lpf <Tf>` | 设置速度低通时间常数 | `vel lpf 0.02` |
| `status` | 查看实际速度、速度给定和跟踪误差 | `status` |

```text
disable
mode vel
vel ramp 300
target 0
enable
target 500
status
```

反转使用 `target -500`，停止使用 `target 0`，然后发送 `disable`。速度振荡时先降低 `vel kp`，响应太慢时再逐步提高。

## 5.5.4 位置闭环模式（`mode pos`）

`pos` 模式的 `target` 单位是机械角弧度，不是电角度。目标是累计机械位置，转一圈约为 `6.283185 rad`。

| 命令 | 作用 | 示例 |
| ---- | ---- | ---- |
| `mode pos` | 选择位置模式，必须在 IDLE 执行 | `mode pos` |
| `target [rad]` | 查询或设置机械位置目标 | `target 6.283` |
| `pos` | 查看位置环和轨迹参数 | `pos` |
| `pos kp <A/rad>` | 设置位置比例增益 | `pos kp 3.0` |
| `pos ki <A/(rad*s)>` | 设置位置积分增益 | `pos ki 0` |
| `pos vkp <A/RPM>` | 设置位置到速度的比例增益 | `pos vkp 0.01` |
| `pos accel <RPM/s>` | 设置加减速斜率 | `pos accel 80` |
| `pos vmax <RPM>` | 设置最大运动速度 | `pos vmax 80` |
| `status` | 查看当前位置和位置误差 | `status` |

```text
disable
mode pos
pos accel 80
pos vmax 80
target 0
enable
target 6.283
status
```

位置模式停止时，将目标设置为当前位置或发送 `disable`。调试时先使用较小的 `pos kp`、`pos accel` 和 `pos vmax`，确认方向正确后再提高。

## 5.5.5 通用状态和安全命令

```text
status          # 查看状态、模式、电流、速度和故障
help            # 查看固件实际支持的命令
fault           # 查询故障码
fault clear     # 排除原因后清除锁存故障，回到 IDLE
disable         # 关闭功率级并停止运行
limit           # 查看软件限流和硬件限流
wave [0|1]      # 控制 FOC-STP 波形流（静默响应，上位机示波器推荐；0 关，1 开）
log [0|1]       # 控制 FOC-STP 波形流（同 wave，标准 CLI 回显；STATUS 心跳不受影响）
telem           # 查询当前掩码与分频
```

常见提示：`state=RUN` 表示电机已经使能，不要重复发送 `enable`；`target is ambiguous in vf` 表示当前为 V/F 模式，应使用 `vq` 和 `rpm`；`enable rejected, state=RUN fault=0` 表示重复使能，不是故障。

## 1. 硬件准备

### 1.1 板子：火柴FOC（bd6s40a_mini_g431 V2）

| 项目 | 参数 |
| ---- | ---- |
| 主控 | STM32G431CBU6 @ 170 MHz |
| 供电 | 标称 24V，最大 48V（本工程按 4S 锂电 ≈14.2V 配置，见 foc_config.h 的 FOC_UDC_V） |
| 电流采样 | 三低边 20mΩ + 片内 OPAMP，**有效增益 ≈1.371**（实测标定 1.367） |
| 编码器口 | PB6/PB7/PB8 = A/B/Z（与霍尔 H1/H2/H3 共用） |
| 串口 | PB3/PB4 = USART2 TX/RX，6.5 Mbaud |
| 按键 | PC10 |

> **与 ST 官方 B-G431B-ESC1 的关系**：采样电路等效——本板电阻是它的 20/3 倍、
> 放大是它的 3/20，乘积相同，所以两板程序可以互相移植（厂家资料确认）。
> 更大的采样电阻还能抑制 MOS 开关谐振电流，保护功率管。

### 1.2 电机（以标配 DJI 2312S 为例）

默认参数按 DJI 2312S 配置（`foc_config.h`）：极对数 7、Rs 0.1Ω、Ls 20µH。
换电机必须改这三个值 + 限流值。**极对数验证方法见 §5.2。**

**DJI 2312S 官方与实测规格对照：**

| 参数项 | 官方规格 | 固件配置 / 实测表现 | 说明 |
| ---- | ---- | ---- | ---- |
| 结构 | **12N14P**（12槽14极） | **极对数 7.0** (`FOC_M0_POLE_PAIRS`) | 极对数 $pp = 14 / 2 = 7$（绝非 6！） |
| 额定电压 | 14.4V（4S 锂电） | 14.4V (`FOC_UDC_V`) | 4S 标称 14.4V，满电 16.8V |
| KV 值 | 800 RPM/V | 实测反电动势 ~815 RPM/V | 线性调制区无弱磁基速约 7500 RPM |
| 最高转速 | **8500 RPM** | 8500 RPM 稳定 / 9000 超频极限 | 官方额定最高转速即为 8500 RPM |
| 工作电流 | 额定 2.5A（带桨悬停） | 软限流 5.2A (`FOC_M0_MAX_CURRENT_A`) | 设为额定 2 倍留加速动态裕量 |
| 瞬态电流 | 空载最大脉冲 **10.5A** | 单拍硬限流 12.0A (`HARD_CURRENT_A`) | 完美包容电机最大加减速脉冲 |

> **历史教训（2026-09-05）**：本电机曾按"ST 历史工程 POLE_PAIR_NUM=6"配置
> 达数月，导致**闭环全模式锁死而 V/F 开环能转**——闭环 θe 的电周期数错
> 1/7，力矩矢量随转子位置乱转；且扫 offset 永远修不平（误差随位置累积，
> 不是常数偏移）。极对数错是"闭环锁死"类故障的头号嫌疑，先查它。
>
> **为什么 ST 历史工程配错 6 也能转、还报出 11000 转？**
> 1. ST 跑的是**无感观测器**：换相电角度 $\theta_e$ 直接由反电动势估算得出，
>    **换相过程根本不乘极对数**！极对数只用于上位机折算显示的机械 RPM。
> 2. 配成 6 时，上位机显示的 RPM 纯粹被放大了 $\frac{7}{6}$ 倍（虚标了 16.7%）：
>    $11000 \times \frac{6}{7} \approx 9428\text{ RPM}$（真实物理电频 1100Hz 对应的极限转速）。
> 3. 但**有感编码器测出的是机械角**，必须严格通过 $\theta_e = dir \cdot pp \cdot \theta_m + offset$
>    刚性折算。极对数差 1，机械转 1 圈电角度就错整整 1 个电周期，力矩方向必然全乱！

> **查不到电机的 Rs/Ls？** 串口发 `ident`，2 秒自动测出来（电机会被吸住锁定），
> 再发 `ident apply` 应用并重整定电流环，`conf write` 写入 Flash 长期生效。

> **注意**：执行过 `conf write` 之后，上电会用 Flash 里的参数**覆盖**
> `foc_config.h` 的默认值——改了 config 却"不生效"时，先 `conf erase`
> 擦除存储再重新上电。**换电机的完整流程见 §5.4。**

### 1.3 接线与电源检查清单

- [ ] 电机 U/V/W 对应接 OUT1/OUT2/OUT3；进入闭环前必须同时核对 PWM 相、采样相和编码器方向
- [ ] 编码器 A/B/Z + 5V/GND（PB6/PB7/PB8）
- [ ] 串口接 USB 转串口（要支持 6.5M 高波特率；CP2102N/FT232H 可以，CH340 不行）
- [ ] 供电电压与 `FOC_UDC_V` 一致（标称 14.4V）
- [ ] **母线并联电容**：板子电源输入端务必**并联一颗 470µF ~ 1000µF 电解电容**！
  高速弱磁加速时存在数安培瞬态抽流，减速时存在反电动势能量微回灌；电容能稳定母线电压，
  防止供电导线电感引起电压跌落触发单片机 BOR 欠压复位，或触发电源短路保护。
- [ ] **电源限流设置**：调试低速时可限流 1~2A；若测试 6000 RPM 以上的高速弱磁，
  请将直流电源限流**放宽至 3.0A ~ 5.2A**（电机空载匀速虽仅 5~10W，但毫秒级加减速
  脉冲电流会超过 1.5A 触发可调电源自身短路保护）。

> 开环验证转向时可以先改变 RPM 正负，不要把“三相顺序随意”带入闭环。
> 若交换任意两根电机相线，必须重新核对 U/V/W 电流采样映射和编码器方向。

## 3. 第一次上电（不接电机也可以做）

上电后串口（6.5M/8N1）会打印：

```
Current offsets U/V/W: 2545, 2543, 2548     ← 三相零偏，应在 2048~3072 之间
FOC ready, 1 axis. Press KEY to run, or type 'help' here.
```

（执行过 `conf write` 的板子还会多一行 `config loaded from flash ...`）

- 如果打印 `Current sensing not ready` → 电流采样自检失败，
  在 Keil Watch 里看 `g_current_shunt_diag.fault_code` 对照 `current_shunt.h` 的故障枚举排查。
- 此时手转电机轴，foc-studio 里 `position`（bit17，机械位置）应该平滑变化，
  `vel_raw`（bit15）显示转速——**不用使能电机就能验证编码器**。

### 上位机配置（foc-studio）

固件 v0.4.0 起遥测协议为 FOC-STP（见 [11 篇](11_FOC-STP遥测协议.md)），

## 4. 逐层验证（重要：一层不通过不进下一层）

### 第 1 层：开环 V/f —— 验证功率级和相序

```text
默认模式就是 vf。直接按一下按键（或串口发 enable）
```

**预期**：电机以 100 RPM 平稳旋转，电流波形（`ia`, `ib`, `ic`，通道字典 bit9~11）是三条干净的正弦。
- 不转/抖动：检查三相接线；降低 `rpm 50` 试试
- 电流超过 1A：电压太高，`vq 0.2` 降低
- 停机发 `disable`（或再按一下按键）

### 第 2 层：编码器校准 —— 验证角度链路

```text
mode vel       ← 切到速度模式（闭环模式按键会先触发校准）
按一下按键     ← 开始校准（或串口发 calib）
```

**预期现象（按顺序）**：上电中点 PWM 观察约 2s → 电机"咔"一下吸住不动
（D 轴对齐 0.8s）→ 缓慢旋转（找 Z 脉冲，最多 10s）→ 碰到 Z 后停止回 IDLE。
串口发 `status` 查看 `calib=1` 表示成功。

> **方向约定**：校准后所有闭环命令的正方向 = 编码器计数的正方向
> （固件内部用 `calib.direction` 自动换算电角度方向，用户不用关心
> `FOC_CALIB_DIRECTION` 的正负）。想反转就给负目标值。

- 校准超时（fault=4）：Z 相没接好，或 `FOC_CALIB_SEARCH_VOLTAGE` 太小转不动
- 校准过流（fault=2）：电机阻值太小，降低 `FOC_CALIB_ALIGN_VOLTAGE`

### 第 3 层：力矩（电流）闭环 —— 验证电流环

```text
mode iq        ← 力矩模式
enable         ← 使能（已校准过才能进）
target 0.2     ← 给 0.2A 的 q 轴电流（空载请勿给过大，防止瞬间超速）
```

**预期**：电机产生一个持续的小扭力（用手能轻松拧住），空载会加速到
反电动势平衡的转速。foc-studio 中勾选 `iq_filt`（Iq 实测）与 `iq_ref`（Iq 给定），二者应紧密跟随且无振荡。
- 振荡/啸叫：电流环带宽太高 → `current bw 500` 降低
- 跟不上/软：带宽太低 → `current bw 2000`
- **测完 `target 0` 或 `disable` 停下**

### 第 4 层：速度闭环

```text
mode vel
enable
target 1000    ← 1000 RPM
```

**预期**：转速平滑爬升到 1000 RPM（受速度斜坡限制平稳上升），
`vel_ctrl`（实际控制转速）稳定跟踪 `vel_ref`（给定转速）。试试 `target -1000` 反转。

### 第 5 层：位置闭环

```text
mode pos
enable         ← 使能瞬间锁定当前位置为原点 (target 语义为相对使能点的偏移 rad)
target 31.4    ← 正向转 5 圈（5×2π，相对使能原点）
target 0       ← 回到使能原点
target -6.28   ← 反向转 1 圈
```

**预期**：电机按梯形轨迹（默认巡航 80 RPM、加减速 80 RPM/s）
平滑转 5 圈后精准停住，用手拧会被"弹"回来（位置保持）。
`enable` 瞬间电机原地锁死不动，`pos_err` 近乎为 0，杜绝了多圈累计位置导致一直旋转的问题。
运动显得"肉"→ 调大 `pos accel` 或 `pos vmax`；想要老式"P 控制器硬拉"
行为 → `FOC_M0_TRAJ_ENABLE` 置 0。

### 第 6 层：纯无感闭环模式（Sensorless Primary：I/F -> VESC 换手）

```text
disable
fault clear
feedback sensorless          ← 激活纯无感主控模式（屏蔽编码器控制权）
feedback if 0.55 500 300     ← 设定拖动电流 0.55A、目标 500 RPM、斜坡 300 RPM/s
mode vel
target 800                   ← 目标 800 RPM（主力无感巡航区）
enable
```

**预期现象（全自动时序，耗时约 1.8~2.5s）**：

1. **0.0~0.4s (IF_START)**：0.55A 直流对齐吸附，注入初态磁链消除积分直流偏置；
2. **0.4~1.5s (IF_ACCEL)**：虚拟电角度按 300 RPM/s 斜坡平稳加速至 500 RPM；
3. **1.5~1.7s (OBS_LOCKING)**：VESC 观测器 7 大物理指标（lock、conf、磁链等）连续达标；
4. **1.7~1.85s (BLEND)**：150ms 动基准平滑过渡，首拍无跳变，速度环 PI 执行 Bumpless Transfer；
5. **1.85s+ (RUN)**：纯无感闭环稳定维持在 800 RPM，速度波动 < 10 RPM，零顿挫。

停机发 `target 0`，随后发 `disable` 并恢复 `feedback sensored`。

## 5. 调参指南

> 本节是提纲。**手把手的详细版**（每个软件怎么配、每个参数的
> 阶跃波形长什么样、怎么判读）在
> [08 · 调参与调试手册](08_调参与调试手册.md)。

### 5.1 调参顺序（铁律：从内环到外环）

内环不稳，外环怎么调都是白费。顺序：**电流环 → 速度环 → 位置环**。

**电流环**（一般不用手调）：填对 Rs/Ls，用 `current bw <rad/s>` 设带宽即可。
带宽经验值：内环带宽 ≥ 10× 外环带宽。16kHz 采样下 500~2000 rad/s 都安全。

**速度环**（`vel kp` / `vel ki`）：
1. 先把 `vel ki` 设 0，从小到大加 `vel kp`，直到阶跃响应快速但不超调；
2. 加 `vel ki` 消除稳态误差，太大会低频振荡；
3. 有静差 → 加 `vel ki`；振荡 → 减 `vel kp` 或加大速度滤波 `FOC_M0_VEL_LPF_TF`（或串口发 `vel lpf <tf>`）。

**位置环**（`pos kp`）：纯 P 就够（速度环里已有积分）。
从 30 开始加，到位快但不过冲为好。

### 5.1.5 调好之后：`conf write` 一次，以后都省事

```text
conf write     ← 电机参数 + 在线调好的 PID + 校准偏移 + 齿槽表全部写入 Flash (v11)
```

之后每次上电：参数自动加载（`status` 里 `calib=0*` 的星号表示偏移来自
存储），按键/`calib` 触发的校准变成**快速索引搜索**——电机不再"咔"地
吸附对齐，只慢转到 Z 脉冲就绪，两秒进入可闭环状态。
编码器与电机的相对位置动过（拆装过）→ `calib full` 重新完整校准 → `conf write`。
**换电机 → 按 §5.4 的完整流程来**，不能只 `calib full`。
想回到 `foc_config.h` 默认值 → `conf erase` 擦除。
（机制详见 [06 · 稳定性与保护](06_稳定性与保护.md) 第 6 节）

### 5.2 验证极对数（换电机必做）

开环模式 `rpm 100` 转起来后，看 foc-studio 中 `vel_raw` / `vel_ctrl` 的转速：

- 若转速 ≈ 100 RPM → 极对数正确；
- 若转速 ≈ 100 × (设定值/真实值)，比如设 6 实际 7 时转速 ≈ 85.7 → 改 `FOC_M0_POLE_PAIRS`。

原理：开环步进角按"设定极对数"换算，编码器测的是真实机械转速，两者的比值暴露真值。

> **只在小转速下可信（≤100 RPM）**：弱电压 slope 曲线下 ≥200 RPM 容易
> 失步爬行，读数不可信。改完 pp 宏后必须按 §5.4 顺序重建存储
> （或递增 `STORE_VER`）——**Flash blob 整包保存 params（含极对数），
> 上电会把旧值覆盖掉新编译的宏，只改宏不重建存储 = 改了白改**。

> **铁证法（相电流 FFT）**：如果比值法存疑，vf 稳态下对相电流 `ia` 做 FFT：
> 基波频率（电频率）÷ 编码器转速频率（机械频率）= 真实极对数。
> 实测记录：9.98 Hz ÷ 1.418 Hz = 7.04。

### 5.4 换电机的完整流程（重要，顺序不能乱）

Flash 存储会在上电时覆盖 config 参数——换电机后如果直接 `calib full`，
校准用的还是**旧电机的极对数**，算出的偏移照样是错的。
（改 `FOC_M0_POLE_PAIRS` 后**递增 `foc_store.c` 的 `STORE_VER`** 是更保险
的做法：旧存储自动失效，无需手动 `conf erase`。）正确顺序：

```text
conf erase     ← 1. 擦除旧电机的存储
（重新上电）    ← 2. 回到 foc_config.h 默认参数
（§5.2 验证极对数，不对就改 config 重新编译烧录）
ident → ident apply ← 3. 自动测量新电机 Rs/Ls 并应用
calib full     ← 4. 完整校准（对齐 + 找 Z）
（逐层验证闭环没问题后）
conf write     ← 5. 新参数 + 新偏移固化
```

> **换相线（A/B 对调）的特殊情况**：编码器方向与电角度方向的关系
> `FOC_CALIB_DIRECTION` 是编译期常数，校准测不出来。若对调过电机
> 相线导致方向反了，需要把该宏取反后重新编译（现象：校准成功但
> 一闭环就朝反方向飞车跳过流）。

### 5.3 串口命令完整表（FOC CLI v2 标准全词命令）

| `acog ...` | 抗齿槽补偿：`acog start`、`acog finish`、`acog enable <0\|1>` | `acog` |

> 1. `target` 适用 `iq/vel/pos` 模式；在 `vf` 模式下转速请使用 `rpm <v>`，电压使用 `vq <v>`；
> 2. 调 `current/vel/pos` 建议在 `disable` 停机状态下调整，避免产生单拍瞬态冲击；
> 3. **`vq` 是持久 RAM 值**：若设过大（如 1.2V）后忘记改回，任何 vf 使能都会在静止转子上灌大电流跳闸（fault=3），出问题先 `vq 0.3` 恢复；
> 4. **参数固化**：在线调好后发送 `conf write` 即可写入 Flash v11，下次开机自动生效。

## 6. 故障对照表

`status` 命令输出的 `fault=`，或 foc-studio 状态仪表盘 / FOC-STP `STATUS` 帧的故障码：

| 码 | 含义 | 常见原因 |
| -- | ---- | ---- |
| 1 | 电流采样失效 | 看 `g_current_shunt_diag.fault_code` 二级故障码 |
| 2 | 校准过流 | 对齐电压太高 / 电机阻值太小 |
| 3 | 运行过流 | 负载过大 / PID 振荡 / `limit` 太小 |
| 4 | 校准超时 | Z 相没信号 / 搜索电压转不动电机 |
| 5 | 校准状态机异常 | 传感器不支持 Z（如虚拟轴上发 `calib`） |
| 6 | 未校准就使能闭环 | 先 `calib` 校准，或切 `mode vf` |
| 7 | 控制环出现 NaN | 参数非法/数值发散 |
| 8 | 堵转 | 电机卡死/负载超限/编码器失效 |
| 9 | 无感观测器故障 (SAFE_STOP) | 纯无感模式下观测器失锁/磁链溢出/角度发散 |
| 10 | 上电参数自检失败 | foc_config 配置错误/Flash 存储损坏 |
| 11 | 母线欠压 (UVLO) | 电池过放/电源掉电/低于 9.0V |
| 12 | 母线过压 (OVLO) | 制动能量倒灌/电源过冲/高于 18.5V |
| 13 | 功率级过温 (OVERTEMP) | 板载 NTC 超过保护阈值（默认 >85°C）/散热不良 |

各项保护的原理与配置详见 [06 · 稳定性与保护](06_稳定性与保护.md)。

清除方法：排除原因后串口发 `f`。

## 7. 更深的调试武器（继承自本工程的黑匣子设计）

- **Keil Watch 必加**：`g_foc_motors`（整个电机对象可视）、
  `g_current_shunt_diag`（采样链路）、`g_system_fault_diag`（复位诊断）。
- 如果出现"电机一使能 MCU 就复位"：重新上电后看 `g_system_fault_diag` 的
  `power_reset_*` 字段——它用 TAMP 备份寄存器记住了复位前最后一个检查点
  和当时的 TIM1 寄存器状态（电源跌落/EMI 问题的取证工具）。

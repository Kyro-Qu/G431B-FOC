# 04 · 上手指南（编译 → 转起来 → 调参）

> 按顺序做，每一步都有"预期现象"。任何一步和预期不符，先停下排查，不要跳步。

## 1. 硬件准备

### 1.1 板子：火柴FOC（bd6s40a_mini_g431 V2）

| 项目 | 参数 |
| ---- | ---- |
| 主控 | STM32G431CBU6 @ 170 MHz |
| 供电 | 标称 24V，最大 48V（本工程按 4S 锂电 ≈14.2V 配置，见 foc_config.h 的 FOC_UDC_V） |
| 电流采样 | 三低边 20mΩ + 片内 OPAMP，**有效增益 ≈1.371**（实测标定 1.367） |
| 编码器口 | PB6/PB7/PB8 = A/B/Z（与霍尔 H1/H2/H3 共用） |
| 串口 | PB3/PB4 = USART2 TX/RX，6.5 Mbaud |
| 按键 | PC10 |

> **与 ST 官方 B-G431B-ESC1 的关系**：采样电路等效——本板电阻是它的 20/3 倍、
> 放大是它的 3/20，乘积相同，所以两板程序可以互相移植（厂家资料确认）。
> 更大的采样电阻还能抑制 MOS 开关谐振电流，保护功率管。

### 1.2 电机（以标配 DJI 2312S 为例）

默认参数按 DJI 2312S 配置（`foc_config.h`）：极对数 7、Rs 0.1Ω、Ls 20µH。
换电机必须改这三个值 + 限流值。**极对数验证方法见 §5.2。**

**DJI 2312S 官方与实测规格对照：**

| 参数项 | 官方规格 | 固件配置 / 实测表现 | 说明 |
| ---- | ---- | ---- | ---- |
| 结构 | **12N14P**（12槽14极） | **极对数 7.0** (`FOC_M0_POLE_PAIRS`) | 极对数 $pp = 14 / 2 = 7$（绝非 6！） |
| 额定电压 | 14.4V（4S 锂电） | 14.4V (`FOC_UDC_V`) | 4S 标称 14.4V，满电 16.8V |
| KV 值 | 800 RPM/V | 实测反电动势 ~815 RPM/V | 线性调制区无弱磁基速约 7500 RPM |
| 最高转速 | **8500 RPM** | 8500 RPM 稳定 / 9000 超频极限 | 官方额定最高转速即为 8500 RPM |
| 工作电流 | 额定 2.5A（带桨悬停） | 软限流 5.2A (`FOC_M0_MAX_CURRENT_A`) | 设为额定 2 倍留加速动态裕量 |
| 瞬态电流 | 空载最大脉冲 **10.5A** | 单拍硬限流 12.0A (`HARD_CURRENT_A`) | 完美包容电机最大加减速脉冲 |

> **历史教训（2026-09-05）**：本电机曾按"ST 历史工程 POLE_PAIR_NUM=6"配置
> 达数月，导致**闭环全模式锁死而 V/F 开环能转**——闭环 θe 的电周期数错
> 1/7，力矩矢量随转子位置乱转；且扫 offset 永远修不平（误差随位置累积，
> 不是常数偏移）。极对数错是"闭环锁死"类故障的头号嫌疑，先查它。
>
> **为什么 ST 历史工程配错 6 也能转、还报出 11000 转？**
> 1. ST 跑的是**无感观测器**：换相电角度 $\theta_e$ 直接由反电动势估算得出，
>    **换相过程根本不乘极对数**！极对数只用于上位机折算显示的机械 RPM。
> 2. 配成 6 时，上位机显示的 RPM 纯粹被放大了 $\frac{7}{6}$ 倍（虚标了 16.7%）：
>    $11000 \times \frac{6}{7} \approx 9428\text{ RPM}$（真实物理电频 1100Hz 对应的极限转速）。
> 3. 但**有感编码器测出的是机械角**，必须严格通过 $\theta_e = dir \cdot pp \cdot \theta_m + offset$
>    刚性折算。极对数差 1，机械转 1 圈电角度就错整整 1 个电周期，力矩方向必然全乱！

> **查不到电机的 Rs/Ls？** 串口发 `id`，2 秒自动测出来（电机会被吸住锁定），
> 再发 `id a` 应用并重整定电流环，`save` 写入 Flash 长期生效。

> **注意**：执行过 `save` 之后，上电会用 Flash 里的参数**覆盖**
> `foc_config.h` 的默认值——改了 config 却"不生效"时，先 `save e`
> 擦除存储再重新上电。**换电机的完整流程见 §5.4。**

### 1.3 接线与电源检查清单

- [ ] 电机 U/V/W 对应接 OUT1/OUT2/OUT3；进入闭环前必须同时核对 PWM 相、采样相和编码器方向
- [ ] 编码器 A/B/Z + 5V/GND（PB6/PB7/PB8）
- [ ] 串口接 USB 转串口（要支持 6.5M 高波特率；CP2102N/FT232H 可以，CH340 不行）
- [ ] 供电电压与 `FOC_UDC_V` 一致（标称 14.4V）
- [ ] **母线并联电容**：板子电源输入端务必**并联一颗 470µF ~ 1000µF 电解电容**！
  高速弱磁加速时存在数安培瞬态抽流，减速时存在反电动势能量微回灌；电容能稳定母线电压，
  防止供电导线电感引起电压跌落触发单片机 BOR 欠压复位，或触发电源短路保护。
- [ ] **电源限流设置**：调试低速时可限流 1~2A；若测试 6000 RPM 以上的高速弱磁，
  请将直流电源限流**放宽至 3.0A ~ 5.2A**（电机空载匀速虽仅 5~10W，但毫秒级加减速
  脉冲电流会超过 1.5A 触发可调电源自身短路保护）。

> 开环验证转向时可以先改变 RPM 正负，不要把“三相顺序随意”带入闭环。
> 若交换任意两根电机相线，必须重新核对 U/V/W 电流采样映射和编码器方向。

## 4. 逐层验证（重要：一层不通过不进下一层）

### 第 1 层：开环 V/f —— 验证功率级和相序

```
默认模式就是 vf。直接按一下按键（或串口发 e 1）
```

**预期**：电机以 100 RPM 平稳旋转，电流波形（ch9~11）是三条干净的正弦。
- 不转/抖动：检查三相接线；降低 `rpm 50` 试试
- 电流超过 1A：电压太高，`vq 0.2` 降低
- 再按一下按键停机

### 第 2 层：编码器校准 —— 验证角度链路

```
m vel          ← 切到速度模式（闭环模式按键会先触发校准）
按一下按键     ← 开始校准
```

**预期现象（按顺序）**：上电中点 PWM 观察约 2s → 电机"咔"一下吸住不动
（D 轴对齐 0.8s）→ 缓慢旋转（找 Z 脉冲，最多 10s）→ 碰到 Z 后停止回 IDLE。
串口发 `s` 查看 `calib=1` 表示成功。

> **方向约定**：校准后所有闭环命令的正方向 = 编码器计数的正方向
> （固件内部用 `calib.direction` 自动换算电角度方向，用户不用关心
> `FOC_CALIB_DIRECTION` 的正负）。想反转就给负目标值。

- 校准超时（fault=4）：Z 相没接好，或 `FOC_CALIB_SEARCH_VOLTAGE` 太小转不动
- 校准过流（fault=2）：电机阻值太小，降低 `FOC_CALIB_ALIGN_VOLTAGE`

### 第 3 层：力矩（电流）闭环 —— 验证电流环

```
m iq           ← 力矩模式
e 1            ← 使能（已校准过才能进）
t 0.3          ← 给 0.3A 的 q 轴电流
```

**预期**：电机产生一个持续的小扭力（用手能轻松拧住），空载会加速到
反电动势平衡的转速。VOFA 看 ch5（Iq 实测）应紧跟 ch6（Iq 给定），无振荡。
- 振荡/啸叫：电流环带宽太高 → `cb 500` 降低
- 跟不上/软：带宽太低 → `cb 2000`
- **测完 `t 0` 或 `e 0` 停下**

### 第 4 层：速度闭环

```
m vel
e 1
t 1000         ← 1000 RPM
```

**预期**：转速平滑爬升到 1000 RPM（受 2000 RPM/s 斜坡限制约 0.5s），
ch2（实际转速）稳定跟踪 ch3（给定）。试试 `t -1000` 反转。

### 第 5 层：位置闭环

```
m pos
e 1
t 31.4         ← 转 5 圈（5×2π）
```

**预期**：电机按梯形轨迹（默认巡航 1000 RPM、加减速 4000 RPM/s）
平滑转 5 圈后精准停住，用手拧会被"弹"回来（位置保持）。
运动显得"肉"→ 调大 `FOC_M0_TRAJ_ACC_RPM_S`；想要老式"P 控制器硬拉"
行为 → `FOC_M0_TRAJ_ENABLE` 置 0。

## 5. 调参指南

> 本节是提纲。**手把手的详细版**（每个软件怎么配、每个参数的
> 阶跃波形长什么样、怎么判读）在
> [08 · 调参与调试手册](08_调参与调试手册.md)。

### 5.1 调参顺序（铁律：从内环到外环）

内环不稳，外环怎么调都是白费。顺序：**电流环 → 速度环 → 位置环**。

**电流环**（一般不用手调）：填对 Rs/Ls，用 `cb` 设带宽即可。
带宽经验值：内环带宽 ≥ 10× 外环带宽。16kHz 采样下 500~2000 rad/s 都安全。

**速度环**（`vp`/`vi`）：
1. 先把 vi 设 0，从小到大加 vp，直到阶跃响应快速但不超调；
2. 加 vi 消除稳态误差，太大会低频振荡；
3. 有静差 → 加 vi；振荡 → 减 vp 或加大速度滤波 `FOC_M0_VEL_LPF_TF`。

**位置环**（`pp`）：纯 P 就够（速度环里已有积分）。
从 30 开始加，到位快但不过冲为好。

### 5.1.5 调好之后：`save` 一次，以后都省事

```
save           ← 电机参数 + 在线调好的 PID + 校准偏移全部写入 Flash
```

之后每次上电：参数自动加载（`s` 里 `calib=1*` 的星号表示偏移来自
存储），按键/`c` 触发的校准变成**快速索引搜索**——电机不再"咔"地
吸附对齐，只慢转到 Z 脉冲就绪，两三秒进入可闭环状态。
编码器与电机的相对位置动过（拆装过）→ `c full` 重新完整校准 → `save`。
**换电机 → 按 §5.4 的完整流程来**，不能只 `c full`。
想回到 `foc_config.h` 默认值 → `save e` 擦除。
（机制详见 [06 · 稳定性与保护](06_稳定性与保护.md) 第 6 节）

### 5.2 验证极对数（换电机必做）

开环模式 `rpm 100` 转起来后，看 VOFA ch2 的编码器转速：
- 若 ch2 ≈ 100 RPM → 极对数正确；
- 若 ch2 ≈ 100 × (设定值/真实值)，比如设 6 实际 7 时 ch2 ≈ 85.7 → 改 `FOC_M0_POLE_PAIRS`。

原理：开环步进角按"设定极对数"换算，编码器测的是真实机械转速，两者的比值暴露真值。

> **只在小转速下可信（≤100 RPM）**：弱电压 slope 曲线下 ≥200 RPM 容易
> 失步爬行，读数不可信。改完 pp 宏后必须按 §5.4 顺序重建存储
> （或递增 `STORE_VER`）——**Flash blob 整包保存 params（含极对数），
> 上电会把旧值覆盖掉新编译的宏，只改宏不重建存储 = 改了白改**。

> **铁证法（相电流 FFT）**：如果比值法存疑，vf 稳态下对 ch9（iu）做 FFT：
> 基波频率（电频率）÷ 编码器转速频率（机械频率）= 真实极对数。
> 2026-09-05 实测：9.98 Hz ÷ 1.418 Hz = 7.04。

### 5.4 换电机的完整流程（重要，顺序不能乱）

Flash 存储会在上电时覆盖 config 参数——换电机后如果直接 `c full`，
校准用的还是**旧电机的极对数**，算出的偏移照样是错的。
（改 `FOC_M0_POLE_PAIRS` 后**递增 `foc_store.c` 的 `STORE_VER`** 是更保险
的做法：旧存储自动失效，无需手动 `save e`。）正确顺序：

```
save e         ← 1. 擦除旧电机的存储
（重新上电）    ← 2. 回到 foc_config.h 默认参数
（§5.2 验证极对数，不对就改 config 重新编译烧录）
id → id a      ← 3. 自动测量新电机 Rs/Ls 并应用
c full         ← 4. 完整校准（对齐 + 找 Z）
（逐层验证闭环没问题后）
save           ← 5. 新参数 + 新偏移固化
```

> **换相线（A/B 对调）的特殊情况**：编码器方向与电角度方向的关系
> `FOC_CALIB_DIRECTION` 是编译期常数，校准测不出来。若对调过电机
> 相线导致方向反了，需要把该宏取反后重新编译（现象：校准成功但
> 一闭环就朝反方向飞车跳过流）。

### 5.3 串口命令完整表（FOC CLI v2 标准全词命令）

| 命令 | 说明 | 示例 |
| ---- | ---- | ---- |
| `help` / `version` / `status` | 帮助信息 / 固件构建版本 / 全轴实时状态与保护快照 | `status` |
| `motor [n]` | 查询或切换当前操作轴（默认单轴 `motor 0`，双轴见 05 篇） | `motor 0` |
| `enable` / `disable` | 闭环使能 / 停机断开功率级 | `enable` |
| `calib [full]` | 快速索引寻零（calib） / 强制完整吸附寻 Z 校准（calib full） | `calib` |
| `calib offset [rad]` | 查询或在线设置电角度偏移（仅 IDLE） | `calib offset 1.0186` |
| `fault [clear]` | 查询故障码 / 清除故障状态恢复 IDLE | `fault clear` |
| `mode <vf\|iq\|vel\|pos>` | 控制模式切换（开环电压 / 力矩闭环 / 速度闭环 / 位置伺服） | `mode vel` |
| `target <val>` | 模式目标给定（iq: A, vel: RPM, pos: rad） | `target 2400` |
| `angle <enc\|ol>` | 切换电角度源（编码器 / 开环自积分） | `angle enc` |
| `vq <v>` / `rpm <v>` | V/F 模式专用：电压 Boost 给定 / 开环转速给定 | `vq 0.3` |
| `vf [slope <v>]` | V/F 曲线斜率查询与设置 | `vf slope 0.0006` |
| `limit [A]` | 查询或动态设置软件过流限制值 | `limit 5.2` |
| `current [bw <rad/s>]` | 查询或设置电流环设计带宽（Kp=Ls·ω, Ki=Rs·ω） | `current bw 2000` |
| `tune ...` | 在线 RAM 调参：`tune fw target <0.7..0.9>`、`tune angle_delay <拍数>` | `tune fw target 0.78` |
| `vel ...` | 速度环细调：`vel kp <v>`、`vel ki <v>`、`vel ramp <RPM/s>` 等 | `vel kp 0.001` |
| `pos ...` | 位置环细调：`pos kp <v>`、`pos accel <v>` 等 | `pos kp 3.0` |
| `ident` / `ident apply` | 启动相电阻/相电感自动测量 / 应用测量结果整定电流环 | `ident` |
| `acog ...` | 抗齿槽补偿：`acog start`、`acog finish`、`acog enable <0\|1>` | `acog` |
| `obs [0\|1\|2 [off]]` | 无感磁链观测器：0关，1开后台对比，2切换为角度源 | `obs 1` |
| `blackbox` | 导出故障前 512 拍（32ms）高频波形十六进制数据 | `blackbox` |
| `conf <read\|write\|erase>` | 整屏回读参数配置 / 保存到 Flash (v11) / 恢复出厂擦除 | `conf read` |
| `log [0\|1]` | VOFA+ JustFloat 遥测流开关（0 关，1 开；打命令建议先 log 0） | `log 0` |

> **说明与调试要点**：
> 1. `target` 适用 `iq/vel/pos` 模式；在 `vf` 模式下转速请使用 `rpm <v>`，电压使用 `vq <v>`；
> 2. 调 `current/vel/pos` 建议在 `disable` 停机状态下调整，避免产生单拍瞬态冲击；
> 3. **`vq` 是持久 RAM 值**：若设过大（如 1.2V）后忘记改回，任何 vf 使能都会在静止转子上灌大电流跳闸（fault=3），出问题先 `vq 0.3` 恢复；
> 4. **参数固化**：在线调好后发送 `conf write` 即可写入 Flash v11，下次开机自动生效。

## 6. 故障对照表

`s` 命令输出的 `fault=` 或 VOFA ch13 ÷100 的整数部分：

| 码 | 含义 | 常见原因 |
| -- | ---- | ---- |
| 1 | 电流采样失效 | 看 `g_current_shunt_diag.fault_code` 二级故障码 |
| 2 | 校准过流 | 对齐电压太高 / 电机阻值太小 |
| 3 | 运行过流 | 负载过大 / PID 振荡 / `lim` 太小 |
| 4 | 校准超时 | Z 相没信号 / 搜索电压转不动电机 |
| 5 | 校准状态机异常 | 传感器不支持 Z（如虚拟轴上发 `c`） |
| 6 | 未校准就使能闭环 | 先 `c` 校准，或切 `m vf` |
| 7 | 控制环出现 NaN | 参数非法/数值发散 |
| 8 | 堵转 | 电机卡死/负载超限/编码器失效 |
| 9 | 上电参数自检失败 | foc_config 配置错误/Flash 存储损坏 |
| 10 | 母线欠压 (UVLO) | 供电低于 9.0V（防锂电过放，持续100ms跳闸） |
| 11 | 母线过压 (OVLO) | 供电高于 18.5V（防制动能量倒灌击穿 MOS） |

各项保护的原理与配置详见 [06 · 稳定性与保护](06_稳定性与保护.md)。

清除方法：排除原因后串口发 `f`。

## 7. 更深的调试武器（继承自本工程的黑匣子设计）

- **Keil Watch 必加**：`g_foc_motors`（整个电机对象可视）、
  `g_current_shunt_diag`（采样链路）、`g_system_fault_diag`（复位诊断）。
- 如果出现"电机一使能 MCU 就复位"：重新上电后看 `g_system_fault_diag` 的
  `power_reset_*` 字段——它用 TAMP 备份寄存器记住了复位前最后一个检查点
  和当时的 TIM1 寄存器状态（电源跌落/EMI 问题的取证工具）。

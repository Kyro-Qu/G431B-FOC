# G431B-FOC 版本历史

本文件按 Git 提交顺序记录项目的功能演进。提交短哈希用于在仓库中定位对应版本；其中 `工作区发布版` 表示本次同步前已经存在、尚未单独提交的改动。

## v0.1 - `361c654` - V/f 基线

- 建立 STM32G431 FOC 工程和基础 PWM/SVPWM 输出。
- 接入三相电流采样、编码器位置反馈和串口调试入口。
- 以 V/f 开环运行验证硬件、电流采样极性和编码器方向。

## v0.2 - `2deda63` - 双轴对象化框架

- 将控制算法整理为电机轴对象，隔离算法层、驱动层、HAL 和应用层。
- 为双电机扩展预留统一的轴状态、参数和控制接口。
- 统一 Clarke/Park、PID、SVPWM 和控制状态机的数据流。

## v0.3 - `c7ae626` - 单电机默认配置与参数测量

- 默认配置收敛为单电机，降低首次上电和调试复杂度。
- 增加 Rs/Ls 参数辨识和参数应用流程。
- 引入带限速、限加速度的梯形轨迹规划。

## v0.4 - `85d56c1` - 缺陷修复与预留模块加固

- 修复审查发现的 8 个控制、边界和状态机问题。
- 加固电流采样、编码器、参数辨识和预留功能模块的异常路径。
- 同步校正相关调试和移植文档。

## v0.5 - `252b90d` - 辨识时序修复

- 延长 Ls 正负激励保持时间，覆盖定时器 CCR 预装载延迟。
- 提高电感辨识在真实 PWM 更新时序下的可靠性。

## v0.6 - `b67273d` - 稳定性与保护

- 增加独立看门狗、Flash 参数存储和快速索引搜索。
- 增加堵转、NaN/无穷值、过流和状态锁存保护。
- 增加 CPU 占用统计和运行状态诊断。

## v0.7 - `6566772` - 稳定性发布修订

- 修复稳定性审查中的剩余问题。
- 校正电机互换和编码器方向相关文档与实现细节。

## v0.8 - `106b8d1` - 审查收尾

- 清理剩余审查告警和边界行为。
- 统一保护、校准、命令行和参数保存流程的接口说明。

## v0.9 - `9335e5d` - 移植、调参和死区补偿

- 新增移植指南、调参手册、代码阅读地图和故障定位流程。
- 加入死区补偿，并补充电流采样、编码器和控制环的工程说明。

## v0.10 - `0df6205` - 预留特性包

- 增加未默认编译的无感观测器、HFI、抗齿槽、弱磁和 CAN 接入预留模块。
- 新增预留特性接入手册，明确启用、验证和回退步骤。

## v0.11 - `fc4b10e` - 图文教学版

- 合并 FOC 原理、Clarke/Park、SVPWM、电流采样和校准流程的图文解释。
- 增加可视化页面和配套图片，完善从原理、架构到代码走读的文档链路。
- 保持 Keil MDK 工程、源码和已有稳定性保护实现不变。

## 工作区发布版 - 2026-09-05

这是本次同步前工作区中尚未单独提交的最新内容，发布后将成为远端 `main` 的最新版本：

- 增加 FDCAN 驱动、演示模块和通信协议文档。
- 扩展串口命令、遥测和运行时调试能力，便于参数、滤波器和保护策略在线验证。
- 改进编码器速度/位置处理、控制环、辨识和电流采样边界条件。
- 收紧 SVPWM 占空比到 `6%..94%`，为下桥导通和三电阻采样保留采样窗口。
- 同步更新 CubeMX 配置、STM32 中断/HAL 初始化和 Keil 工程文件。

## 版本使用建议

- 首次调试使用 v0.3 之后的单电机默认配置，并按 `Docs/04_上手指南.md` 逐步校准。
- 需要稳定运行时使用 v0.6 之后的保护和 Flash 参数存储实现。
- 需要 CAN 时使用工作区发布版，并先阅读 `Docs/10_FDCAN通信协议.md` 和 `MDK-ARM/Code/foc/Driver/can/CAN_FD_Demo.md`。
- 任何硬件迁移都应以 `Docs/07_移植指南.md` 为入口，不要直接复用当前板级电流增益和引脚配置。

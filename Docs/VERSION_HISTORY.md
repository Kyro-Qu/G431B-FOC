## 工作区无感与 HFI 定案更新 - 2026-09-09

- **纯无感主控模式（Sensorless Primary: I/F -> VESC 闭环）**：
  - 建立完备 7 状态机：`SENSORLESS_IF_START`（0.50A/400ms 直流对齐吸附并向观测器注入初态磁链）、`SENSORLESS_IF_ACCEL`（开环虚拟电角 300 RPM/s 稳态拖动至 350~500 RPM）、`SENSORLESS_OBS_LOCKING`（连续 8000 拍/500ms 磁链与置信度门禁判定）、`SENSORLESS_BLEND`（150ms 动基准角度平滑过渡，首拍连续零阶跃，速度环 PI 无扰重平衡）、`SENSORLESS_RUN`（纯无感 500~1000 RPM 闭环稳定运行）以及 `SENSORLESS_LOST / SAFE_STOP`（失锁受控关断 PWM 保护）。
  - 500~1000 RPM 多速度段验证：800 RPM 速度估计波动收敛至 7.02 RPM（<10 RPM），角度 RMS 维持在 7.0°~9.8°，全程零失锁、零过流。
- **高频注入（HFI）影子模块实现与物理可行性定案**：
  - 在快环 16 kHz 逐拍实现 8 kHz 方波脉动高频注入、逆变器输出电压叠加、同步电流反 Park 投影解调与二阶自适应跟踪 PLL。
  - 完成 DJI 2312S 表贴电机的双轴高频电感辨识：实测 $L_d=103.4\mu\text{H}, L_q=96.6\mu\text{H}$，凸极率仅约 $-6.64\%$，理论差分载波电流仅 $21.4\text{ mA}$；而板载采样硬件单个 LSB 达 $29.35\text{ mA}$，调制信号被量化噪声与死区抖动淹没。
  - 科学定案：HFI 算法代码与影子框架 `VERIFIED`，当前电机与采样硬件下的物理可行性归档为 `NOT_FEASIBLE_FOR_DJI2312S_MATCHSTICK`，代码作为影子模式保留以备后续 IPMSM 电机复用，严禁接入换相控制角。
- **文档与测试套件完善**：
  - 更新 `Docs/08_调参与调试手册.md` §3.6 纯无感启动与运行调试指南；
  - 更新 `Docs/09_预留特性接入手册.md` §2.2 明确注明本项目自定义工程门槛与实测证伪案例；
  - 归档 `Docs/评估报告/HFI_影子评测与物理可行性定案报告_20260909.md`；
  - 提供多工况自动化测试套件 `tools/test_sensorless_primary_suite.py`。

## 版本使用建议

- 首次调试使用 v0.3 之后的单电机默认配置，并按 `Docs/04_上手指南.md` 逐步校准。
- 需要稳定运行时使用 v0.6 之后的保护和 Flash 参数存储实现。
- 需要 CAN 时使用工作区发布版，并先阅读 `Docs/10_FDCAN通信协议.md` 和 `MDK-ARM/Code/foc/Driver/can/CAN_FD_Demo.md`。
- 任何硬件迁移都应以 `Docs/07_移植指南.md` 为入口，不要直接复用当前板级电流增益和引脚配置。

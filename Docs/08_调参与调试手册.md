### 1.1 foc-studio 配置步骤（3 分钟）

1. Chrome/Edge 打开 https://kyroqu.xyz/foc-studio/ ，点"连接"选串口，波特率 6.5M；
2. 连接后仪表盘立刻由 10 Hz STATUS 心跳刷新（母线电压、状态、故障码）；
3. 点 `Log ON`（`log 1`）开波形流；左侧 32 通道字典勾选要看的通道，
   会自动下发 `telem mask`，未勾选通道不占带宽；预设按钮有"电流调试/速度调试/位置轨迹/无感诊断"；
4. 终端页直接敲 CLI 命令，回显与波形互不打断；
5. 带宽紧张（蓝牙/低波特率）时 `telem rate 100` 降速，时间轴自动跟随 ACK 回传的真实速率。
   命令行抓数：`python tools/foc_capture.py --ch vel_ctrl,iq_filt,vq --secs 10`。

**调试各环时推荐的通道组合（32 位通道字典，详见 [11 篇](11_FOC-STP遥测协议.md)）：**

| 调什么 | foc-studio 预设 / 勾选通道 | 调试观察重点 |
| ---- | ---- | ---- |
| 编码器好坏 | `theta_e`（bit0 电角度）、`vel_raw`（bit15 编码器转速） | 手转轴看角度锯齿推进与转速连续性 |
| 电流环 | 预设【电流调试】：`iq_filt`（bit5 实测）+ `iq_ref`（bit6 给定）+ `id_filt`（bit4） | 阶跃响应 1~2 拍到位，Id 始终贴 0 |
| 速度环 | 预设【速度调试】：`vel_ctrl`（bit2 实际转速）+ `vel_ref`（bit3 速度给定） | 梯形斜坡平稳跟踪，超调 <10% 且无静差 |
| 位置环 | 预设【位置轨迹】：`pos_ref`（bit16 给定）、`position`（bit17 机械位置）、`vel_ctrl` | 梯形速度规划，到位利落、手拨抗扰不振荡 |
| 供电监控 | `vbus_fast`（bit26 实时母线采样）+ 状态栏 Dashboard | 观察加速抽流跌落与高速刹车能量回灌 |
| 无感诊断 | 预设【无感诊断】：`obs_err`（bit22 角差）、`obs_conf`（bit23 置信度）、`obs_speed` | 观测器收敛性与动基准平滑换手 |
| 故障排查 | `ia`, `ib`, `ic`（bit9~11 三相电流）+ Dashboard 故障灯 / STATUS 帧 | 三相正弦对称性、死区与过流瞬态捕获 |

## 2. 适配一台新电机：完整流程

### 2.0 你需要知道电机的什么

| 参数 | 哪里来 | 拿不到怎么办 |
| ---- | ---- | ---- |
| 极对数 pp | 铭牌/规格书；或数转子磁铁个数 ÷ 2 | §2.3 开环法实测，1 分钟 |
| 相电阻 Rs | 规格书 | 串口 `ident` 自动测 |
| 相电感 Ls | 规格书 | 串口 `ident` 自动测 |
| 额定/峰值电流 | 规格书 | 从小限流起步（1~2A），摸着电机温度加 |

> 云台电机（Rs 几 Ω、Ls 几百 µH）、航模电机（Rs 几十 mΩ、Ls 十几 µH）、
> 轮毂电机都适用本工程；差别只是参数量级和限流值。
> Rs 越小的电机越"猛"，校准电压和限流都要更保守。

### 2.1 第一步：保守配置 + 上电

改 `foc_config.h`（先不追求准确，追求安全）：

```c
FOC_M0_POLE_PAIRS      按已知值填（不确定就先填标称，§2.3 验证）
FOC_M0_MAX_CURRENT_A   电机额定电流的一半（先保守）
FOC_M0_HARD_CURRENT_A  软限 × 1.25
FOC_CALIB_ALIGN_VOLTAGE / SEARCH_VOLTAGE
                       大电机 0.5~1V；小云台电机 1~2V（内阻大）；
                       航模电机 0.2~0.3V（内阻小，电压稍大电流就爆）
```

编译烧录，**串限流电源（1~2A）上电**。若之前 `conf write` 保存过别的电机：
先 `conf erase` 再重新上电（详见 04 §5.4）。

### 2.2 第二步：`ident` 自动测 Rs / Ls / 极对数 / 磁链与 Ke

工程支持全套参数自动化在线辨识与单项快速测量：

```text
ident full    ← 执行全套辨识（Rs -> Ls -> Pp -> Flux -> Done，耗时约 6s）
ident rs      ← 仅辨识相电阻与电感（转子吸住静止，耗时约 2s）
ident pp      ← 仅辨识极对数（开环 2Hz 匀速旋转 4 周期，自动计算位移比与残差）
ident flux    ← 仅辨识永磁磁链与反电势常数 Ke（开环 300 RPM 稳态相量模值采样）
ident show    ← 查看最近一次测量的数据缓存与精度残差
ident apply   ← 一键将测得的 Rs/Ls/Pp/Ke 注入电机对象，并自动重整定电流环带宽
conf write    ← 固化到 Flash
```

实机辨识输出示例（DJI 2312S，COM44）：
```text
ident start: Full Suite (Rs->Ls->Pp->Flux, ~6s)
ident: Rs=0.3822 ohm  Ls=315.17 uH  (I=1.00A)
ident: Pole Pairs = 7 (raw=7.05, residual=0.7%)
ident: Flux=0.00147 Wb, Ke=1.87 V/krpm (rpm=300, Iq=3.60A)
ident DONE: Identification complete!
apply with 'ident apply', then 'conf write'
```

- **Rs 测量**：固定电角度 $\theta_e=0$ 给升压斜坡，直至 $I_d = 1.0\text{A}$ 稳态平均：$R_s = \bar{V}_d / \bar{I}_d$；
- **Ls 测量**：转子继续吸住，$d$ 轴高频方波注入，按极性累计伏秒积分与电流增量 $\Delta i$：$L_s = \Sigma(V - R_s i) dt / \Sigma \Delta i$；
- **极对数 Pp 测量**：缓升对齐后以平稳电角频率（2Hz）旋转固定 4 个完整电周期（$8\pi$ rad），读取机械增量 $\Delta \theta_m$，理论值 $P_{p,\text{calc}} = \Delta \theta_e / \Delta \theta_m$，并校验残差 $\le 10\%$；
- **磁链 $\psi_f$ 与 $K_e$ 测量**：以稳态转速旋转，采样端电压与电流，利用正交相量解耦模型 $E = \sqrt{V_{mag}^2 - (R_s I_{mag})^2}$ 消除开环功角偏差，提取永磁磁链 $\psi_f = E / \omega_e$ 并换算三相线峰值反电势常数 $K_e$；
- **一键自整定**：执行 `ident apply` 后，系统会自动根据测得的 $R_s$、$L_s$ 和目标控制带宽（默认 $1500\text{ rad/s}$），自动更新 $d/q$ 轴电流环 PID（$K_p = L_s \cdot \omega_c$，$K_i = R_s \cdot \omega_c$）。
- `ident FAIL: no measurable current` → 电机没接好，或 Rs 太大
  （>2Ω 时把 `foc_ident.c` 里 `IDENT_MAX_VOLTAGE_V` 加大）；
- 测量值和规格书差 20% 以内都正常（绕组温度、接触电阻）。

### 2.3 第三步：验证极对数（开环法，必做）

```text
vq 0.3        ← 电压按 §2.1 的建议值
rpm 100
enable        ← 电机开环旋转
```

看 foc-studio **`vel_raw` / `vel_ctrl`（编码器实测转速）**：

- 转速 ≈ 100 → 极对数对了；
- 转速 ≈ 100 × 设定pp/真实pp（例：设 6 实际 7 时转速 ≈ 85.7）→
  改 `FOC_M0_POLE_PAIRS` 重新编译；
- 转速抖或不转 → 电压加一点，或负载太重。

> 只在 ≤100 RPM 下可信：≥200 RPM 弱电压下会失步爬行，读数不可信。
> 存疑时用**相电流 FFT 铁证法**：`ia` 基波频率 ÷ (机械转速/60) = 真实极对数。
> 改完 pp 后务必处理存储覆盖问题（04 §5.2/§5.4）：Flash blob 整包
> 存 params，上电旧值会盖掉新编译宏——递增 `STORE_VER` 或 `conf erase` 重建。

顺手看 **`ia`, `ib`, `ic` 三相电流**：应是干净的三相正弦，幅值 =
电压/Rs 量级。毛刺大、缺相 → 回 04 §6 故障表排查。

### 2.4 第四步：校准 + 逐层闭环

```text
disable → mode vel → calib → 等寻零完成 → enable → target 200
```

按 04 §4 的第 3~5 层逐层验证（力矩 → 速度 → 位置）。
第一次闭环给小目标，手边留断电开关。

## 3. PID 调试：一步一步来

### 3.0 三条铁律

1. **从内环到外环**：电流环 → 速度环 → 位置环。内环不稳，
   外环调了也是白调；
2. **一次只动一个参数**，动完看阶跃响应再动下一个；
3. **用阶跃测试评价**，不要凭手感："突然改一次目标值，看实际值
   怎么追上去"的波形，是唯一客观的评语。

### 3.1 电流环（通常不用手调）

本工程电流环按 ODrive 公式自整定：`Kp = Ls×带宽`，`Ki = Rs×带宽`。
**Rs/Ls 准（用 `ident` 测），它就是稳的**——这是先测参数的最大意义。

你唯一要选的是**带宽**（`current bw <rad/s>` 命令，默认 2000 rad/s）：

| 带宽 | 适用 |
| ---- | ---- |
| 500 | 保守起步、大电感电机 |
| **1000 ~ 2000（默认）** | 绝大多数情况 |
| 2000~3000 | 需要更快电流响应（激烈的速度环）时 |

**阶跃测试**：`mode iq` → `enable` → 交替发 `target 0.2` / `target 0.5`，
foc-studio 看 `iq_filt`（实测）追 `iq_ref`（给定）：

```text
好：      ┌──────      一拍到两拍跟上，无振荡
          │
坏-震荡： ┌∿∿∿∿──      bw 太高 或 Ls 填大了 → 降 bw
坏-爬坡： ╱‾‾‾‾‾       bw 太低 或 Ls 填小了 → 加 bw
```

同时 **`id_filt`（Id）应始终贴着 0**；Id 跟着 Iq 一起晃 → 校准角度不准
（重新 `calib full`）或转速高时解耦没开（`FOC_M0_DECOUPLE`）。

> 啸叫（尖锐高频叫声）= 电流环在振荡，先降 bw；调好后仍有轻微
> 电磁噪声是 16kHz PWM 的正常声音。

### 3.2 速度环（`vel kp` / `vel ki`，重点手调对象）

进入条件：电流环阶跃已达标。`mode vel` → `enable`。

**第 1 步：只调 Kp（先把 Ki 关掉）**

```text
vel ki 0
vel kp 0.001      ← 起步值
target 500 / target 1000 交替发，看 vel_ctrl 追 vel_ref
```

Kp 每次 ×2：`0.001 → 0.002 → 0.004 …`，直到阶跃响应**开始出现
小幅超调或抖动**，然后退回一半。这就是临界法的朴素版。

```text
太软：vel_ctrl 缓慢爬向 vel_ref，还差一截（稳态误差大）→ 继续加 vel kp
临界：快速到位，末端一两个小波动          → 退回一半，进第 2 步
太硬：持续抖动/嗡嗡声，电机发热           → vel kp 减半
```

**第 2 步：加 Ki 消稳态误差**

```text
vel ki 0.001 起步，每次 ×2
```

- 目标：阶跃后 `vel_ctrl` **最终精确压线** `vel_ref`（无稳态误差）且不超调
  过多（<10%）；
- ki 太大：到位后慢速"荡秋千"（低频振荡）→ 减半；
- ki 太小：带负载后转速总是差一点 → 加。

**第 3 步：抗扰测试**

匀速运转时用手轻捏轴（模拟负载扰动），`vel_ctrl` 应快速凹陷后恢复：
恢复太慢 → ki 加一点；恢复时振荡 → kp 或 ki 减一点。

**低速抖动专项**（<100 RPM 常见）：
- 开启抗齿槽力矩前馈补偿（见 §3.4）；
- 或者提高编码器线数（CPR 2048 在 50 RPM 时每毫秒才 1.7 个计数，
  分辨率见底了）。

**加减速太猛/太肉**：`vel ramp <RPM/s>`（目标斜坡）
不是 PID，但直接决定"给 target 3000 时冲多快"。

### 3.3 位置环（`pos kp` + 阻尼 + 轨迹参数）

进入条件：速度环阶跃已达标。`mode pos` → `enable`。

位置环结构：**位置 PI 直接输出 Iq + 速度阻尼项**（`pos vkp`）。
`pos vkp` 是扰动稳定性的关键——为 0 时位置环是**无阻尼弹簧**，
手拨大角度释放会等幅强摆（2026-09-06 实测教训）：

```text
pos kp 3.0 起步 → target 6.28（转一圈）看响应 → 每次 +2
pos vkp 0.020 起步（A/RPM，阻尼）→ 手拨扰动测试收敛 → 振铃则 +0.01
```

- 到位慢、末端"蹭"很久 → 加 pos kp；
- 到位后来回过冲 → 减 pos kp，或速度环重调（多半是速度环不够硬）；
- **手拨大角度释放强摆/振铃** → 加 pos vkp（0.01 步进，上限约 0.05）；
- **静止锁定有抖动** → pos vkp 过大放大编码器噪声，减 0.005 试；
- 好的标准：到位干脆、无过冲、手拨释放单拍回位不振铃；
  当前默认（kp=3.0 / ki=0.1 / vkp=0.020）实测 ±2.2 rad 扰动释放零振铃。

**轨迹参数**（运动的"性格"，比位置增益 `pos kp` 更影响观感）：

| 参数（宏 / 命令行） | 作用 | 调法 |
| ---- | ---- | ---- |
| `FOC_M0_POS_VEL_LIMIT` / `pos vmax <rpm>` | 巡航最高速度 | 长距离移动的最高转速 |
| `FOC_M0_TRAJ_ACC_RPM_S` / `pos accel <rpm/s>` | 加减速度 | 越大越"跟手"，太快会冲击过流 |
| `FOC_M0_TRAJ_ENABLE=0` | 编译期关掉轨迹 | 退回"P 硬拉"风格（不推荐） |

foc-studio 看 `vel_ctrl`：位置阶跃时转速应走出**梯形**（升-平-降），
说明轨迹规划在工作。

> **物理边界提示**：位置环伺服能力受 `pos vmax`（默认 80 RPM）与限流（5.2A）
> 约束。若把转子暴力甩到数千 RPM（反电动势接近母线电压），全力刹车时
> 制动能量倒灌会触发 OVLO(fault=11) 过压停机——这是保护电路按设计动作，
> 不是失稳。位置模式下请不要超高速甩动转子。

### 3.4 高速与弱磁调试（冲 8000 ~ 9000 RPM 实操指南）

当速度环在 2400 RPM 稳定后，如果需要继续向电机的物理极限（DJI 2312S 官方上限 8500 RPM）冲击，
需要进行弱磁调参。

#### 1. 弱磁控制的核心原理
随着转速上升，反电动势 $E = K_e \cdot \omega$ 越来越大，端电压矢量模长 $|V| = \sqrt{v_d^2 + v_q^2}$
逐渐逼近逆变器的母线电压极限（$U_{dc}/\sqrt{3} \approx 8.31\text{V}$ @14.4V）。
- 当 $|V| > V_{target}$ 时，弱磁控制器自动产生**负向直轴电流给定 $I_{d,\text{ref}} < 0$**；
- 负向 $I_d$ 削弱转子永磁体磁链，压低反电动势，腾出电压空间让电机继续升速。

#### 2. 在线调参旋钮（全支持 `tune` 命令在线修改，RAM only 安全无风险）：

| 命令 | 默认值 | 推荐调参值 | 作用说明 |
| ---- | ---- | ---- | ---- |
| `tune fw target <比率>` | **0.780** | **0.85 ~ 0.88** | 电压利用率门槛。默认 78% 稳在 8000~8500 RPM；调到 88% 可冲 9000 RPM。 |
| `tune angle_delay <拍数>` | **0.50** | **0.80 ~ 1.00** | 电角度超前补偿。9000 RPM 下每拍转过 $24^\circ$ 电角度，提高补偿消除高频相位滞后。 |
| `limit <电流A>` | **5.20** | **5.20 ~ 6.00** | 软限流保护。高速下负 $I_d$ 与 $I_q$ 合成电流会增加，根据电源能力适度设定。 |
| `vel ramp <RPM/s>` | **100** | **300 ~ 500** | 调参时加速爬坡，快速到达高速区。 |

#### 3. 高速工况下硬件与供电的“两个铁律”：
1. **电源输入端必须并联 470µF ~ 1000µF 电解电容**：高速加减速存在瞬间毫秒级脉冲抽流，
   且弱磁换向瞬间有轻微能量回灌。没有大电容缓冲，导线感抗会瞬间拉跌电压触发单片机 BOR 欠压复位！
2. **直流电源限流值请放宽至 3.0A ~ 5.2A**：空载 8500 转稳态功率虽然仅 6~8W（平均电流不到 0.6A），
   但冲刺瞬间的瞬态电流会刺穿 1.5A 导致电源硬件短路保护跳闸。

#### 4. 高速下编码器准不准？（实测验证方法）

- **看一致性**：foc-studio 对比 `vel_raw`（底层滑窗速度）与 `vel_ctrl`（高阶控制滤波速度）。
  实测在 9000 RPM（正交脉冲 307 kHz）下，两路速度偏差仅 **0.6 ~ 2.1 RPM（误差 < 0.02%）**，
  证明 TIM4 硬件解码无丢步。
- **看零漂**：多圈往返后发 `mode pos` 看绝对位置，实测多圈高速旋转后回到原点误差 $<1.5^\circ$ 机械角，
  证明固件在高速 RUN 状态下旁路 Z 脉冲的设计完全杜绝了累积误差。

### 3.5 调参完成的验收单

- [ ] 电流阶跃：1~2 拍到位，无振荡，Id 贴 0
- [ ] 速度阶跃：快速到位，超调 <10%，无稳态误差

## 3.6 纯无感启动与运行调试指南（I/F + VESC 观测器）

针对无编码器场合，本工程实现了 **I/F 开环平滑拖动 → VESC 约束磁链观测器闭环接管** 的工业级纯无感方案。

### 1. 无感分段控制策略

- **0 ~ 350 RPM（静止与极低速段）**：
  采用 **I/F 开环拖动与初始直流吸附**。
  - 阶段 1：直轴电流 $I_d$ 从 0 斜坡升至 $0.50\text{A}$（对齐吸附 400ms），将转子稳定在零电角度处，并向 VESC 观测器注入物理初态磁链（消除纯积分直流偏置）；
  - 阶段 2：虚拟电角度按加速度斜坡加速推进（默认 $300\text{ RPM/s}$），$I_d$ 恒定维持 $0.50\text{A}$ 牵引转子升速。
- **350 ~ 500 RPM（自适应换手候选区）**：
  由 **VESC 内生指标与门** 决定何时接管，**严禁转速硬切**！
  - 准入门禁：`obs_lock == 1` 且 `conf_window >= 0.70` 且 `qualified_streak >= 8000`（连续 500ms 达标）且反电势磁链模长处于标称区间 $[0.4\psi_n, 2.5\psi_n]$；
  - 150ms 动基准平滑过渡：控制角首拍零突变接入，开环 $I_d$ 线性衰减至 0，闭环 $I_q$ 建立，速度环 PI 执行 Bumpless Transfer（无扰平滑重平衡）。
- **中高速（>500 RPM）**：
  VESC 纯无感闭环稳定维持。
- **失锁保护**：
  发生严重角差发散或磁链失效时，受控关断 PWM 并进入 `SAFE_STOP`（触发 `fault=9`），不盲目重启。

### 2. 调参命令与旋钮

| 命令 | 默认值 | 作用说明 |
| ---- | ---- | ---- |
| `feedback sensorless` | - | 激活纯无感主控模式（编码器仅作为后台对比诊断，不进控制链） |
| `feedback sensored` | - | 恢复有感主控模式（编码器作为主控角度源） |
| `feedback if <电流A> [转速RPM] [加速度RPM/s]` | 0.55A 500RPM 300RPM/s | 调整 I/F 开环拖动参数。空载推荐 0.50~0.60A，重载可提至 0.70A |
| `feedback blend <时间s>` | 0.150s | 开闭环过渡时间（推荐 100~200ms） |
| `sensorless status` | - | 实时观察 VESC 观测器磁链、锁定状态、置信度与对齐品质 |
| `feedback` | - | 实时观察角度仲裁状态、子状态、开环速度与观测器速度 |

### 3. 稳态实测性能基准（2026-09-09 实机大榜）

- **启动与换手成功率**：500~2000 RPM 闭环切换成功率 **100%**，启动耗时约 1.8 秒；
- **主力巡航工作点（800 ~ 2000 RPM）**：
  - 800 RPM：实测转速 794.5 RPM（偏差 -5.5 RPM），速度波动 RMS < 10 RPM；
  - 1500 RPM：实测转速 1504.7 RPM（偏差 +4.7 RPM）；
  - 2000 RPM：实测转速 2001.2 RPM（偏差仅 +1.2 RPM），极佳反电势信噪比；
- **安全防线**：任何外力强行堵转或拔除相线，10ms 内捕获失锁并受控关断 PWM，转入 SAFE_STOP（fault=9）。

## 4. 调试方法论：出问题时的定位顺序

```text
第 1 步  串口发 status     → 状态？故障码？（对照 04 §6 / 06 §9 表）
第 2 步  foc-studio 看波形 → 三相电流形状？Iq 跟不跟给定？角度连续吗？
第 3 步  Keil Watch 深挖   → safety 跳闸快照、shunt 诊断、PID 内部
第 4 步  黑匣子            → 板子复位过？g_system_fault_diag 看现场
```

**四个最常见的"新手第一坑"：**

1. **一使能就跳过流（fault=3）**：十有八九是校准角度错了 →
   `calib full` 重校准；还不行就查 `FOC_CALIB_DIRECTION`（04 §5.4）。
2. **vf 测试连环过流跳闸但接线无误**：`vq` 设的开环 boost 是
   持久 RAM 值，设过大电压（如 1.2V）后所有 vf 使能都会在静止
   转子上灌大电流 → `vq 0.3` 恢复。
3. **速度环方向对、就是控不住**：`vel kp` 从太大值起步了 →
   回到 §3.2 第 1 步从 0.001 重来。
4. **改了 foc_config.h 没效果**：板子里有 Flash 存储覆盖 →
   `conf erase` + 重新上电（06 §6）。

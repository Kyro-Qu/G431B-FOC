# 09 · 预留特性接入手册 —— 需要台架慢慢调的高级功能

> `MDK-ARM/Code/foc/Reserve/` 里放着五个**已写好、已单独编译验证、
> 但没有加入 Keil 工程**的高级特性。它们的共同点：**必须在真电机上
> 反复调试才能做对**，盲加进主固件只会埋雷。
>
> 本篇教你：每个特性是什么、**一步步怎么加进工程、怎么调、怎么判断
> 成功、失败怎么回退**。你按需要一个一个来，理解一个再接一个。

## 0. 通用流程：怎么把一个 Reserve 文件"接进"工程

所有五个特性都遵循同样的四步。以后每章只讲"特有的接线和调试"。

**第 1 步：加进 Keil 工程**
1. Keil 左侧 Project 窗口 → 右键某个分组（如 `foc/App`）→
   Add Existing Files → 选 `Reserve/xxx.c`；
2. `.h` 不用加（只要 include 路径能找到——Reserve 目录已在
   工程根下，用相对路径 `../Reserve/xxx.h` 引用即可，或把
   `./Code/foc/Reserve` 加进 C/C++ 的 Include Paths）。

> ⚠ 用 Keil GUI 加文件，**不要手动编辑 .uvprojx**——手改容易
> 弄坏 XML 导致工程打不开。（本工程就踩过这个坑。）

**第 2 步：在合适的位置调用**（每章给出具体接入点）

**第 3 步：加串口命令**（在 `foc_cmd.c` 的 `cmd_execute` 里仿照
现有命令加一个分支，方便台架上开关/触发）

**第 4 步：编译 → 台架验证 → 不行就回退**
回退 = Project 里右键该文件 Remove，恢复到已验证的主固件。
**每次只接一个特性，验证通过再接下一个。**

## 1. 无感 FOC（`foc_sensorless`）——历史参考

### 1.1 它解决什么
让电机在**没有编码器**的情况下闭环（靠反电动势估算转子角度）。
适合航模/风机/泵这类"只要转速、不要精确位置、且一直在转"的场合。
**低速和静止不行**（反电动势太小），所以需要"开环启动 → 切闭环"。

### 1.2 前置条件
- 电流环必须已经调好（无感完全建立在电流环之上）；
- 知道电机的磁链 λ（头文件有公式，或用 KV 估）；
- 电机能空载或轻载启动。

### 1.3 接入点
在 `foc_motor.c` 的快环 `foc_motor_fast_loop()`，**电角度选择那段**
（现在是"CALIB/开环用步进角，否则用编码器角"）加一个无感分支：

```c
/* 伪代码：真正接入时替换角度来源 */
if (angle_source == FOC_ANGLE_SENSORLESS) {
    m->theta_e = foc_sensorless_update(&g_sl, m);
    /* 速度反馈也换成观测器的： */
    m->velocity_rpm = foc_sensorless_speed_e_rads(&g_sl)
                      / m->params.pole_pairs * FOC_RADS_TO_RPM;
}
```
（需要在 `foc_angle_source_t` 里加一个 `FOC_ANGLE_SENSORLESS` 枚举，
并在 App 层放一个全局 `foc_sensorless_t g_sl`。）

### 1.4 调试步骤（foc-studio 全程盯着）

1. `foc_sensorless_init` 填入你估的 λ，先把 `switch_err_rad` 放宽到
   0.5（约 29°）容易切换；
2. 力矩模式给一个小 Iq，`foc_sensorless_start` → 电机开环 ramp；
3. foc-studio 勾选两个通道：**`obs_theta`（观测器角度）** 和 **`theta_e`（控制电角度）**，看它们是否
   在 ramp 到目标转速后逐渐重合——重合了才可能切；
4. 切到 CLOSED 后，缓慢加大 Iq 看能否稳住；抖动→降 PLL 增益，
   跟不上→升 gamma；
5. 反复调 `ramp_target_rpm`（切换转速）到"能稳定切换的最低值"。

### 1.5 成功判据 / 失败回退
- ✅ 切换后手动轻微加减载，观测器角度不发散、转速平滑；
- ❌ 切换即失步/反转 → λ 差太多（重估）或切换转速太低（调高）；
- 回退：angle_source 用回编码器，Remove 文件。

## 2. HFI 低速无感（`foc_hfi`）——静止/低速也免编码器

### 2.1 它解决什么
无感的短板是低速，HFI 用高频注入补上这一段（静止也能知道转子方向）。
**这是五个里最难的**，先读 1（无感）跑通再碰它。

### 2.2 前置条件（本项目工程硬门槛与物理约束）

本项目实测定案明确：电机必须具备明显的**磁阻凸极性**或**高灵敏度电流采样链路**。

1. **凸极差值与采样门槛**：
   - 理论最大高频差分载波电流 $\Delta i_{q,\text{max}} \approx \frac{V_h \Delta t}{L_d L_q} \cdot \frac{|L_d - L_q|}{2}$；
   - 必须**显著大于采样硬件的单 LSB 量化步长**（至少 2~3 倍以上）。
2. **实测证伪案例（DJI 2312S + MatchStick）**：
   - DJI 2312S 为瓦片磁钢表贴式 SPMSM，5轮实测 $L_d=103.4\mu\text{H}, L_q=96.6\mu\text{H}$，凸极率仅约 $-6.64\%$；
   - 在 $V_h=1.0\text{V}$ 注入下，理论载波电流仅约 $21.4\text{ mA}$，而板载 $20\text{m}\Omega$ + $G=1.371$ 运放在 12-bit ADC 下单 LSB 达 $29.35\text{ mA}$！
   - **定案结论**：由于信号完全被逆变器死区与量化噪声淹没，**当前电机/板卡下 HFI 物理不可行，代码仅保留为影子（obs5_hfi），严禁接入实际换相控制角**！低速段统一采用方案 1 的 I/F 开环平滑接管。
3. **后续复用条件**：
   - 仅当更换为凸极性强烈的内嵌式永磁电机（IPMSM，如 $L_q/L_d > 1.2$）或更高分辨率采样硬件（如 16-bit ADC、更小量程或过采样滤波）时，方可重新启用 HFI 接管评估。

### 2.3 接入点
在快环**电流采样之后、电压命令 SVPWM 之前**调用
`foc_hfi_update(&g_hfi, m)`：它读 `m->i_dq` 解调、更新角度、
把注入电压叠加到 `m->v_dq.d`。用它的返回值作为 `m->theta_e`。

### 2.4 调试步骤
1. `v_inject` 从 1V 起（小电机 0.5V），PLL 增益先给保守值；
2. 电机**堵住不动**，`foc_hfi_start`，在 foc-studio 或 Keil Watch 中看解调误差应收敛到 0 附近、`theta_e` 稳定；
3. 手动缓慢转动电机轴，`theta_e` 应跟随；跟不动→加 `v_inject`
   或 PLL 增益；抖→减；
4. 极性判别验证：故意给 `theta_guess` 一个反的初值（+π），
   看状态机能否在 POLARITY 阶段自动翻正。
5. 与方案 1 衔接：低速用 HFI，转速升高后切观测器（进阶，先分别调通）。

### 2.5 成功判据 / 失败回退
- ✅ 静止堵转时 theta_e 指向真实转子电角度（用编码器对比验证）；
- ❌ demod 不收敛/乱跳 → 凸极性不够（换电机）或注入太小；
- 回退：Remove 文件，低速仍用编码器/开环。

## 3. 抗齿槽补偿（`foc_anticog`）——低速丝滑

### 3.1 它解决什么
低速转动时"一顿一顿"（齿槽力矩）。标定出每个角度的补偿电流，
运行时前馈抵消，低速平顺度肉眼可见提升。**位置/速度环调好后再做。**

### 3.2 接入点（两处）
- **标定采样**：速度模式恒速运行时，慢环里每拍调
  `foc_anticog_calib_sample(&g_ac, m->theta_mech, m->iq_ref)`；
- **运行前馈**：慢环算出 iq_ref 后加一句
  `m->iq_ref += foc_anticog_feedforward(&g_ac, m->theta_mech)`。

### 3.3 调试步骤
1. 串口加命令：`acog` → `foc_anticog_calib_begin`；
2. 速度模式 **20 RPM** 恒速转，让它转 ≥3 整圈（`total_samples`
   看进度）；
3. 停下，`foc_anticog_calib_finish`——返回 0 说明有角度没采到
   （转太快跳桶/没转够整圈），降转速重来；
4. 开启前馈，同样 20 RPM 转，对比开/关：foc-studio 看转速波动（`vel_ctrl` / `vel_raw`）
   应明显变平。

### 3.4 成功判据 / 失败回退
- ✅ 低速转速波动减小、听感/手感变顺；
- ❌ 反而更抖 → 标定时转速不稳（先把速度环调稳）或极对数/编码器
   方向问题导致表错位；
- 回退：`g_ac.enable=0` 即关（表还在，可随时再开）。

## 4. 弱磁扩速（`foc_fieldweaken`）——冲到反电动势极限之上

### 4.1 它解决什么
转速被母线电压顶住（电压饱和）时，注入负 Id 削弱磁场换更高转速。
**表贴电机（SPM）平时不需要**（Id=0 即最优），只有确实要超速时才用。

### 4.2 前置条件与风险
- 电流环调好、高速能稳定运行；
- **退磁风险**：`id_max_a` 必须小于电机退磁电流（查规格书，
  保守取额定的 30~50%）——超了会永久损坏磁铁；
- 弱磁电流增加发热，注意温度。

### 4.3 接入点
慢环算完 iq_ref 后：
```c
float id_ref = foc_fw_update(&g_fw, &m->v_dq,
                             m->drv->u_dc * INV_SQRT_3, dt_slow);
/* 把 id_ref 作为 d 轴电流环给定（当前工程 Id 恒 0，
   需要把快环里的 "0.0f - i_dq.d" 改成 "id_ref - i_dq.d"） */
```
disarm 时调 `foc_fw_reset`。

### 4.4 调试步骤
1. `id_max_a` 先给一个**很小**的值（额定 10%）试水；
2. 速度模式给超过"电压饱和转速"的目标，看转速能否突破；
3. foc-studio 勾选 `id_ref` 与 `id_filt`：饱和时应变负，退出高速时回 0；
4. 一点点加 `id_max_a`，同时**盯电机温度**，绝不超退磁电流。

### 4.5 成功判据 / 失败回退
- ✅ 最高转速提升，id_ref 随电压余量自动进退；
- ❌ 高速振荡 → `ki` 太大减半；过热 → id_max 调小；
- 回退：`foc_fw_reset` + Id 给定改回 0。

## 5. CAN 总线控制（`foc_can`）——多轴联网/上位机指挥

### 5.1 它解决什么
用 CAN 总线远程控制（设目标/模式/使能/清故障）+ 心跳广播状态。
多个电机节点挂一条总线，或给主控（如树莓派/另一块 MCU）指挥。

### 5.2 前置条件（硬件 + CubeMX）
- **硬件**：确认本板 FDCAN 引脚接了 CAN 收发器芯片（如 TJA1051）
  并引出到接线端子——**没有收发器接不了总线**；
- **CubeMX**：开 FDCAN1（经典模式，500k 或 1M），生成初始化代码；
- **hal_conf.h**：确认 `HAL_FDCAN_MODULE_ENABLED` 已启用
  （本工程已启用）；
- NVIC：FDCAN1_IT0 中断，优先级 ≥5。
- 文件用 `#ifdef HAL_FDCAN_MODULE_ENABLED` 包裹，**没配 CAN 时
  加进工程也是空编译，不会报错**，可以放心先加。

### 5.3 接入点
- `foc_can_init()` 放在 `foc_app_init` 末尾（MX_FDCAN1_Init 之后）；
- `foc_can_task()` 放进 `foc_app_task`；
- 收帧回调 `HAL_FDCAN_RxFifo0Callback` 已在 .c 里实现（weak 覆盖），
  CubeMX 生成的同名弱函数会被它替换。

### 5.4 调试步骤
1. 用 USB-CAN 分析仪（如 CANalyst-II）接总线；
2. 上电应看到 100ms 一次的心跳帧（ID=0x200）；
3. 发一帧 ID=0x203 数据 `01`（arm）→ 电机使能；发目标帧
   ID=0x201 + float → 电机响应；
4. 拔掉分析仪 500ms 后电机应自动 disarm（心跳超时保护生效）。

### 5.5 成功判据 / 失败回退
- ✅ 收发正常、超时保护有效；
- ❌ 收不到 → 波特率/收发器/终端电阻(120Ω)问题；
- 回退：Remove 文件（或 CubeMX 关 FDCAN）。

## 附：五个特性的依赖与难度一览

| 特性 | 依赖 | 难度 | 硬件要求 |
| ---- | ---- | ---- | ---- |
| 抗齿槽 | 速度环调好 | ★★☆ | 无 |
| CAN | CubeMX 配 FDCAN | ★★☆ | CAN 收发器 |
| 无感（中高速） | 电流环调好 | ★★★ | 无 |
| 弱磁 | 电流环+高速稳定 | ★★★ | 注意退磁 |
| HFI（低速无感） | 无感+凸极电机 | ★★★★★ | 凸极性电机 |

**建议顺序**：抗齿槽 / CAN（独立、好验证）→ 无感 → 弱磁 → HFI。
